# 꼬리 질문 500개 승격

기존 500문항의 ‘더 파고들 거리’ 1,508개 항목을 검토했습니다. 동일 문구를 제외한 후보는 1,291개이며, 그중 기존 독립 문항을 가리키는 반복 추천과 표현만 다른 항목을 우선 제외했습니다. 여러 분야의 원문 295개에서 세부 논점 500개를 선정해 총 1,000문항으로 확장했습니다.

## 선정과 답변 범위

- 부모 제목을 그대로 복제하지 않고, 질문 자체에 기술·상황·판단 기준을 넣었습니다.
- 최근 추가한 일반 CS·AI 에이전트 문항에서 이미 다룬 주제의 단순 링크는 무조건 다시 만들지 않았습니다.
- 한 분야의 후보를 모두 소진하기보다 원문의 범위를 나눠 OS·동시성·언어·DB·분산·인프라·웹·게임·설계·ML을 포함했습니다.
- 원문과 같은 기술을 다뤄도 메모리 공개·실제 회수, 메시지 전송·업무 ACK, 전체 상태·증분 이벤트처럼 판정할 계약이 다른 항목은 세부 문항으로 분리했습니다.
- 새 답변은 좁은 질문에 직접 답하는 핵심 설명과 적용 조건·실패·검증을 제공합니다. 부모의 긴 답변을 복사해 분량을 늘리지 않으며 `answerMinutes: 5`를 붙이지 않습니다. 기존 500개 보강본은 그대로 유지합니다.
- 제품·언어 버전에 따라 다른 부분은 구현 계약을 확인하도록 범위를 명시합니다. 이번 작업이 모든 플랫폼에서 실행 검증됐다는 뜻은 아닙니다.

## 출처와 이동

[`followup-promotions.json`](followup-promotions.json)에 정확히 500개 항목의 새 ID·제목, 부모 ID, 원문 항목 위치·문구를 기록했습니다. 선정된 원문 문구는 이 목록에 보존됩니다.

새 문항의 `promotedFrom: {id, prompt}`는 부모와 원문 질문을 가리킵니다. 부모의 ‘더 파고들 거리’는 새 문항으로 연결되며, 새 문항 상단과 본문 끝에서 부모로 돌아갈 수 있습니다. 부모의 사이드바에도 가능한 범위에서 새 문항을 우선 배치합니다. 기존 연습의 대표 연결 일부는 보존합니다.

새 문항에 다시 세 개의 비슷한 꼬리 질문을 자동 생성하지 않았습니다. 새 사이드바는 명시된 기본·연관 문항과 기존 추천을 사용하고, 이를 새 맥락을 가진 꼬리 질문인 것처럼 표시하지 않습니다.

## 검증

인덱스와 파일의 일대일 대응·ID 및 제목 중복·메타데이터·본문·원문 링크를 확인합니다. 승격 목록의 수와 부모 문구·새 문항의 계보를 테스트하고, 브라우저에서 부모→세부 문항→부모 이동과 ‘심화 질문’ 태그 필터를 확인합니다. 랜덤 덱은 기존 목록과 새 ID를 조정하는 방식을 그대로 사용합니다.
