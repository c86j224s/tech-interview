# 전체 학습 범위 관리

## 완료의 기준

1,000개 질문에 노트 1,000개를 만드는 작업이 아니다. 하나의 학습 주제가 여러 질문을 설명할 수 있다. 반대로 질문에 노트 링크가 있어도 그 질문의 구체적인 동작·실패 조건까지 설명되지 않았다면 완료가 아니다.

`/notes/coverage/`는 질문 1,000개를 기존 원문과 승격 심화 문항의 500개 묶음으로 빠짐없이 보여 준다. 이 묶음은 탐색용 출처 관계이지 최종 주제 분류도, 필요한 노트 개수도 아니다. 여러 묶음을 같은 주제로 통합하거나 한 묶음의 별도 심화 주제를 나누는 판단은 본문 작성 시 수행한다. 현재 단계에서 전체 주제 분류·본문 작성이 끝났다고 보고하지 않는다.

## 상태

- `covered`: 명시한 질문의 원리·예제·실패 조건을 노트 본문에서 검토했다. 제품 실행 실험을 뜻하지 않는다.
- `partial`: 구체적인 보강 범위를 `remaining`에 기록한다.
- `unreviewed`: 참고 노트는 있지만 이 기준으로 별도 검토하지 않았다. 자동 상속 링크도 이 상태다.
- `missing`: 연결된 노트가 없다. 제목만으로 자동 생성한 노트로 완료 수를 늘리지 않는다.

`docs/study-coverage-reviews.json`에는 직접 검토한 질문 ID, 노트 ID, 상태, 설명 범위와 본문 앵커를 기록한다. 검토 이력이 없는 문항을 자동으로 완료 처리하지 않는다. 신규 질문은 목록에 자동 등장하며, 존재하지 않는 질문·노트·앵커와 중복 판정은 검증 오류다. 제목·본문이 크게 바뀌면 앵커 존재만 믿지 않고 의미 검토도 다시 해야 한다.

## 2026-09-14 후속 작성분

첫 후속분으로 12개 주제를 추가했다.

- 조건 변수: 재획득 경쟁, predicate, 대기 진입, 종료 정책과 객체 수명
- 교착 상태: 대기 그래프, 전역 잠금 순서, 실행기 고갈, 라이브락·기아
- 진입 제어: 실행·대기·바이트·기한 예산과 하위 시스템 용량
- MVCC: 읽기 시점과 오래된 버전의 보존
- 쓰기 편향: 집합 불변식과 직렬화 재시도
- 캐시 지연 채우기: 무효화와 원자 버전 게시
- singleflight: 공유 작업과 개별 대기자의 수명
- 펜싱: 단조 토큰과 실제 저장소의 원자 집행
- Fenwick tree: lowbit 구간, prefix 합과 점 갱신
- 블룸 필터: 비트 반례, 용량, 반영 지연과 재구축
- 가상 메모리: TLB miss·페이지 폴트·실제 I/O 구분
- 분류 지표: 혼동 행렬, 양성 비율과 판정 임계값

총 33개 노트이며 이 검토 체계에서 31문항을 본문 검토 완료, 2문항을 일부 설명으로 판정했다. 기존 노트의 가치가 없어졌다는 뜻이 아니라 링크 개수와 새 검토 기준을 구분한 결과다. 상태별 최신 개수는 생성되는 범위 페이지를 기준으로 한다.

## 검산과 실행 한계

Fenwick tree의 점 갱신 200회마다 36개 구간을 기준 배열과 비교해 7,200개 구간 합을 검산했고, 각 노드의 lowbit 구간 합도 확인했다. 블룸 필터 용량·포화 근사, 분류 지표와 양성 비율 변화, 가상 주소 계산도 Python으로 대조했다. 동시성·DB·분산 장애 예는 제어할 순서와 예상 결과를 기술했으며 실제 운영 제품에서 장애 주입을 수행한 결과는 아니다.

## 2026-09-15 알고리즘·자료구조 작성분

12개 노트를 추가해 총 45개 노트·그림 50개가 되었다. 균등 범위 난수, Fisher–Yates, reservoir, 가중 추출을 각 분포의 계약에 맞춰 나눴다. 단조 스택, 이동 구간 최댓값, 위상 정렬, Union-Find, MST, 지연 전파 세그먼트 트리, 동적 배열, 외부 정렬에도 각각 추적 예·슈도코드·복잡도와 실패 조건을 추가했다.

새 노트와 기존 이진 탐색·퀵소트의 직접 관련 범위 28문항을 검토했다. 상태는 본문 검토 완료 59개, 부분 설명 2개, 연결만 있는 검토 대기 133개, 연결 없음 806개다. 이것은 질문별 검토 현황이며 전체 학습 주제의 완성을 의미하지 않는다. DP·기수 정렬·소수 체·균형 트리 등 같은 분야에도 미작성 범위가 남아 있다.

검산은 `python3 scripts/verify-algorithm-study.py`로 재실행할 수 있다. 단조 스택·덱은 작은 배열 1,093개를 기준 구현과 비교하고, 셔플 24개 선택 경로·reservoir 12개 경로를 전수 열거했다. 무작위 작은 MST 200개를 모든 신장 트리 조합과 비교하고, 지연 전파 구간 합 8,200개와 대입·덧셈 태그 합성, 위상 정렬·복구 DSU·병합·수치 예를 확인했다. 이 스크립트는 설명을 검산하는 별도 구현이며, 운영용 알고리즘 구현이나 모든 입력의 정형 증명을 대신하지 않는다.

## 남은 작성의 묶음

전체 제목 1,000개를 확인했으며, 아래는 다음 작성·통합의 탐색 순서다. 항목 하나를 노트 하나로 강제하지 않는다.

1. 동시성·OS: 메모리 순서·회수, 세마포어, 스케줄링, 파일 내구성, NUMA·할당
2. 데이터베이스: 정규화·함수 종속, SQL 의미, 인덱스 세부, WAL·복원, 마이그레이션, Redis·검색 저장소의 남은 주제
3. 분산 시스템: 합의·Raft·Paxos, 논리 시계·일관성, 샤딩, 메시지 중복·순서·보관, NATS·JetStream·SQS, saga
4. 네트워크·보안: DNS·HTTP·TLS·QUIC, IOCP·epoll 수명, 인증 프로토콜·세션·키 회전, 웹 입력과 권한 경계
5. 언어·런타임: C++ 소유·이동·코루틴, Java 타입·메모리·JVM, JavaScript 바인딩·이벤트 루프, Python·Go 동시 실행과 객체 모델
6. 알고리즘·자료구조·게임: 남은 정렬·그래프·DP·샘플링, 균형 트리·타이머, 공간·충돌·경로·틱·권위 이전
7. 인프라·설계·성능: Kubernetes·확장·배포·복구, 객체 책임·계약·테스트, 추적·지표·부하 측정
8. 웹·모바일·ML·에이전트: 렌더링·CSS·CORS, iOS 수명·좌표·소유, 학습·평가 분리, 도구·문맥·위임·평가의 남은 범위

후속 작업은 범위 목록에서 미작성·부분 설명을 고른 뒤 실제 질문 본문을 읽고 노트를 작성한다. 같은 원리를 반복 복사하거나, 여러 제품의 계약을 하나의 일반론으로 덮지 않는다.
