01

구두 답변

정의를 외우기보다, 원리와 조건을 연결해 설명해 보세요.

반드시 그렇지는 않습니다. 비동기성과 논블로킹은 구분해야 합니다. 비동기는 작업의 완료를 호출 흐름과 분리해서 전달하는 방식이고, 블로킹 여부는 결과를 기다리는 동안 어떤 실행 자원을 점유하는지에 관한 문제입니다. 그래서 API 하나보다 요청부터 완료까지의 실행 모델을 봐야 합니다.

비동기 작업에서 future를 받았더라도 결과가 준비되기 전에 요청 처리 스레드에서 get()을 호출하면 그 지점에서는 동기적으로 대기합니다. 이벤트 루프에서 기다리면 같은 루프의 다른 연결까지 지연됩니다. 제한된 스레드 풀의 모든 워커가 같은 풀에 제출한 하위 작업을 기다린다면 **스레드 풀 고갈(thread-pool starvation)**이 발생하고, 대기를 풀어 줄 실행 자원이 없다면 교착 상태로 이어질 수도 있습니다.

여기서는 무엇이 멈추는지도 구분해야 합니다. Go의 채널 대기는 보통 고루틴을 파킹하고 OS 스레드는 다른 고루틴을 실행할 수 있습니다. 반면 동기 시스템 호출이나 FFI는 OS 스레드를 점유할 수 있어 런타임의 처리가 달라집니다. C++ 코루틴도 별도 스레드나 논블로킹 I/O를 보장하지 않습니다. 중단 조건과 재개 위치는 awaiter와 실행기, 즉 executor의 구현에 달려 있습니다.

논블로킹으로 바꿨다고 처리 용량이 늘어나는 것도 아닙니다. 병목이 DB라면 스레드 대신 미완료 요청과 대기열이 쌓일 수 있습니다. **백프레셔(backpressure)**로 하위 시스템의 처리 속도를 상위에 반영하고, 진입 제어로 동시 작업과 대기열을 제한해야 합니다. 데드라인과 취소 전파도 함께 설계해야 이미 필요 없어진 작업이 자원을 계속 점유하는 일을 줄일 수 있습니다.

진단할 때는 CPU 사용률만 보지 않고 스레드 덤프, 워커 풀의 활성·대기 수, 큐 대기 시간, 이벤트 루프 지연과 p99 응답 시간을 함께 보겠습니다. 핵심은 비동기 API를 썼는지가 아니라, 어디서 어떤 실행 자원을 기다리며 포화됐을 때 어떻게 반응하는가입니다.

02

득점 포인트

이해가 드러나는 지점을 확인해 보세요.

  • 실행 모델의 경계를 구분한다. 비동기 완료 전달, OS 스레드 블로킹, 코루틴·고루틴의 중단을 같은 현상으로 취급하지 않는다.
  • 고갈이 교착으로 이어지는 조건을 설명한다. 완료 작업도 동일한 포화 풀에 의존하고 별도의 진행 경로가 없는 경우를 짚는다.
  • 병목이 이동할 수 있음을 설명한다. 스레드 대기를 없애도 DB 처리 용량은 그대로일 수 있으며 백프레셔와 제한된 대기열이 필요하다고 판단한다.
  • 가설과 관측 지표를 연결한다. 낮은 CPU와 높은 지연만으로 결론 내리지 않고 스택·풀 점유·큐 대기·이벤트 루프 지연을 비교한다.
03

감점 포인트

놓치기 쉬운 조건과 오해를 짚어 보세요.

  • “비동기는 별도 스레드, await는 논블로킹을 보장한다”고 말한다. 문법이나 반환 타입만으로 스케줄링과 실제 I/O 방식을 결정할 수 없다.
  • “future의 get은 항상 블로킹된다”고 말한다. 결과 준비 여부와 future 구현을 확인해야 하며, 지연 실행 정책이라면 대기 경로에서 작업이 실행될 수도 있다.
  • “스레드 풀을 키우면 고갈 문제는 해결된다”고 단정한다. 같은 의존 구조를 유지하면 다시 고갈될 수 있고 연결·메모리 등 다른 자원의 한계를 앞당길 수 있다.
  • “취소 신호를 보내면 서버 작업도 즉시 중단된다”고 말한다. 취소는 협력적이며 호출 대상이 지원하는 중단 지점과 자원 정리 규칙이 필요하다.
04

더 파고들 거리

하나 더 질문하며 이해의 범위를 넓혀 보세요.

  • C++ 코루틴이 중단·재개될 때 프레임과 I/O 버퍼의 수명은 누가 책임지며, 취소와 완료가 경합하면 어떻게 정리할까요?
  • 이벤트 루프 지연과 하위 DB 지연을 구분하려면 분산 추적에서 큐 대기와 실제 실행 시간을 어디에 기록해야 할까요?
  • 동기 라이브러리를 전용 풀에 격리할 때 풀 크기, 대기열 상한, 데드라인을 어떤 기준으로 정할까요?
  • 백프레셔가 적용되지 않는 푸시형 입력에서는 부하 차단, 샘플링, 디스크 버퍼링 중 무엇을 선택할까요?
