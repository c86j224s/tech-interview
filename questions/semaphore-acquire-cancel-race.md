# 허가를 얻기 전과 얻은 직후 취소가 발생합니다. 허가를 누수하거나 두 번 반환하지 않게 어떻게 구분하나요?

## 구두 답변

허가 획득 전에 취소됐다면 반환할 허가가 없고 획득한 뒤라면 실제 작업 수명에 맞춰 한 번 반환해야 합니다. cancel과 acquire가 경합할 때 어느 결과가 확정됐는지 상태를 구분합니다.

일반적인 finally release만으로 획득 실패까지 반환하면 상한이 깨질 수 있습니다. 외부 I/O가 취소를 무시하면 응답 종료 시 허가를 먼저 돌려주지 않습니다. 경합·예외·중복 완료를 결정적으로 시험합니다.
