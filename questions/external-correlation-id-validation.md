# 외부가 보낸 상관 ID를 로그에 씁니다. 길이·문자·개행·출처 검증이 왜 필요한가요?

## 구두 답변

외부 상관 ID는 공격자가 길이·개행·특수 문자열을 넣을 수 있어 로그 주입·저장 폭주·검색 혼동을 만들 수 있습니다. 길이·문자 규칙을 검증하고 내부 발급 ID와 외부 값을 구분합니다.

그 값을 사용자 신원이나 권한 증거로 사용하지 않습니다. structured logging과 안전한 인코딩을 적용하고 원문 민감값을 복제하지 않습니다. 중복 ID·잘못된 형식·대량 입력에서 진단 연결과 상한을 검증합니다.
