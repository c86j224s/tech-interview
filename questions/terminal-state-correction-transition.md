# 완료·취소 상태를 다시 바꿔야 하는 정정이 있습니다. 종료 상태를 몰래 덮지 않고 어떤 별도 전이를 두나요?

## 구두 답변

완료 상태를 원래 진행 상태로 덮어쓰면 과거 결과와 외부 효과의 의미를 잃을 수 있습니다. 정정·재개·환불 같은 별도 전이와 요청 ID·원장을 만들어 새로운 사실로 기록합니다.

허용 선행 상태와 version을 원자 검사하고 중복 정정을 막습니다. 이미 사용한 권리나 외부 결제는 단순 rollback이 아닙니다. 정상 완료와 늦은 보상·재요청 경쟁을 시험합니다.
