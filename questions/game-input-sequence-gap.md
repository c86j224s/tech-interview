# 서버가 받은 게임 입력 번호가 중간에 비었습니다. 기다림·다음 입력 처리·재동기화 중 무엇을 선택하나요?

## 구두 답변

입력 번호의 누락이 재전송 가능한 명령인지 최신 방향으로 대체 가능한 상태인지 먼저 구분합니다. 피해·아이템 사용을 건너뛰거나 중복 적용하면 안 되지만 오래된 위치 표시는 최신값으로 수렴시킬 수 있습니다.

누락 대기 시간과 버퍼 크기를 제한하고 범위를 넘으면 snapshot·마지막 확정 입력 번호로 재동기화합니다. 누락 번호가 영원히 올 것이라 가정하지 않습니다. 서버의 허용 입력 연령·틱 귀속과 공정한 처리 규칙을 고정해 리플레이로 검증합니다.
