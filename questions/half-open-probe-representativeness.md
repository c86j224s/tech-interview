# 서킷의 half-open 시험 호출은 성공하지만 실제 트래픽은 실패합니다. 시험 표본과 복귀 기준을 어떻게 바꾸나요?

## 구두 답변

시험 요청이 가벼운 health endpoint뿐이면 실제 쓰기·큰 응답·특정 지역 장애를 대표하지 못합니다. 안전하게 실행 가능한 대표 호출을 제한된 수·동시성으로 보내 성공률과 지연을 확인합니다.

샘플 수가 너무 적으면 우연한 성공으로 전체 트래픽을 열 수 있어 단계적 확대와 재실패 조건을 둡니다. 쓰기 시험은 격리·멱등성·승인이 필요합니다. 옛 상태에서 시작한 늦은 성공이 새 브레이커 세대를 닫지 않도록 상태 version도 검사합니다.
