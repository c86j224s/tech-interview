# 간선을 추가하며 두 정점이 이미 연결됐는지 반복 확인합니다. Union-Find는 무엇을 저장하나요?

## 구두 답변

Union-Find는 서로 겹치지 않는 집합마다 대표자를 두고, 두 원소가 같은 대표자를 가지는지로 같은 집합인지 확인합니다. 그래프에 간선을 추가할 때 양 끝이 같은 집합이면 이미 경로로 연결됐다는 뜻입니다. 실제 경로 자체를 저장하는 자료구조는 아닙니다.

find는 부모를 따라 대표자를 찾고 union은 두 대표 집합을 합칩니다. 작은 트리를 큰 트리에 붙이거나 rank를 사용해 높이를 억제하고, find 중 지나간 노드가 대표자를 바로 가리키도록 경로 압축을 하면 긴 연산열에서 매우 작은 분할 상환 비용을 얻을 수 있습니다. 모든 호출이 엄밀히 상수 시간이라고 말하지는 않겠습니다.

저는 간선 추가 중심의 연결성이나 Kruskal의 사이클 검사에 사용하겠습니다. 간선을 삭제해 집합을 다시 나누는 작업은 기본 Union-Find로 쉽게 지원되지 않습니다. 테스트는 이미 같은 집합의 union, 자기 연결, 긴 합치기 순서를 포함합니다. 대표자 ID가 서비스에서 의미를 부여한 리더나 최소 원소라는 보장은 없으므로 필요하면 별도 메타데이터로 관리하겠습니다.

## 득점 포인트

- 집합 대표와 실제 경로를 구분한다.
- 경로 압축과 크기 기반 합치기를 설명한다.
- 삭제와 대표 ID의 한계를 명시한다.

## 감점 포인트

- 대표자는 항상 가장 작은 원소라고 말한다.
- 간선 삭제도 기본 구조로 즉시 처리한다고 말한다.
- 연결됐다는 결과로 경로를 바로 얻는다고 말한다.
