# 순수 계산 결과를 캐시하려는데 입력 객체가 가변입니다. 값 동일성·해시·캐시 무효화를 어떻게 정하나요?

## 구두 답변

입력 객체 주소를 키로 쓰면 같은 객체의 내용 변경 후 낡은 결과를 재사용할 수 있습니다. 실제 계산에 영향을 주는 값·정책 version으로 cache key를 만들거나 입력을 불변으로 유지합니다.

깊은 해시는 계산·직렬화 비용이 들고 순서·NaN·정규화 의미가 필요합니다. 외부 시각·전역 설정을 몰래 읽으면 순수성 전제 자체가 깨집니다. 입력 mutation·동등 객체·cache eviction·정책 변경에서 결과를 기준 계산과 비교합니다.
