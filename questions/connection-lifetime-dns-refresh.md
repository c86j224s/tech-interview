# DNS 전환을 따라가도록 연결 최대 수명과 유휴 수명을 설정합니다. 재연결 폭주 없이 어떻게 분산하나요?

## 구두 답변

연결 최대 수명은 오래된 주소·인증 상태에서 주기적으로 벗어나게 하고 유휴 수명은 쓰지 않는 자원을 정리합니다. 둘은 목적이 다르며 같은 TTL로 무조건 맞추지 않습니다.

모든 연결이 동시에 만료되면 handshake·DNS 부하가 몰리므로 jitter와 교체 예산을 둡니다. 실행 중 요청을 무조건 끊지 않고 새 수락을 줄여 drain합니다. DNS 새 값·옛 연결·재시도·실제 원본 주소를 각각 관찰합니다.

## 득점 포인트

- 연결 최대 수명은 오래된 주소·인증 상태에서 주기적으로 벗어나게 하고 유휴 수명은 쓰지 않는 자원을 정리합니다. 둘은 목적이 다르며 같은 TTL로 무조건 맞추지 않습니다.
- DNS 새 값·옛 연결·재시도·실제 원본 주소를 각각 관찰합니다.
