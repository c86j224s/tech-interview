# 여러 인스턴스가 공유하는 서킷 상태 저장소가 실패했습니다. 로컬 상태와 호출 허용은 어떻게 결정하나요?

## 구두 답변

공유 상태 저장소의 장애가 모든 호출을 무제한 허용하게 만들지 않도록 로컬 circuit·동시성·deadline 안전망을 둡니다. 마지막 정상 상태를 얼마나 유지할지와 통합 판단이 불가능할 때의 기능 축소를 명시합니다.

결제 불확정을 성공으로 대체하지 않고, 중요하지 않은 조회는 제한된 stale 결과를 사용할 수 있습니다. 저장소 복구 때 모든 인스턴스가 한꺼번에 half-open 시험을 보내지 않도록 제한·지터를 둡니다. 로컬 실패와 실제 하위 장애를 분리해 관측합니다.
