# 연관된 설정을 한 번에 바꿀 수 없습니다. 구·신 값이 섞인 중간 조합을 어떻게 안전하게 제한하나요?

## 구두 답변

호환되는 중간 조합을 먼저 정의하고 검증된 설정 묶음을 하나의 version으로 게시합니다. 저장소가 원자 갱신을 지원하지 않으면 준비 상태의 새 묶음을 완성한 뒤 참조 포인터를 전환하는 방식이 가능합니다.

요청은 루트를 한 번 읽어 같은 버전의 timeout·retry·pool 값을 사용합니다. 보안 회수처럼 즉시 반영해야 하는 정책은 요청 snapshot과 별도 검사합니다. 실패한 묶음은 게시하지 않고 마지막 정상값·오류·현재 적용 버전을 남깁니다.

## 득점 포인트

- 호환되는 중간 조합을 먼저 정의하고 검증된 설정 묶음을 하나의 version으로 게시합니다. 저장소가 원자 갱신을 지원하지 않으면 준비 상태의 새 묶음을 완성한 뒤 참조 포인터를 전환하는 방식이 가능합니다.
- 실패한 묶음은 게시하지 않고 마지막 정상값·오류·현재 적용 버전을 남깁니다.
