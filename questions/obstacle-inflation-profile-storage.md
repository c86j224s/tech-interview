# 장애물을 캐릭터 반경만큼 팽창시키면 좁은 통로가 사라집니다. 여러 크기의 경로 데이터를 어떻게 저장하나요?

## 구두 답변

에이전트 반경만큼 장애물을 팽창시키면 점 경로로 몸체 통과를 검사할 수 있지만 작은 통로가 해당 크기에는 막힙니다. 여러 크기에 전체 맵 복사본을 둘지 clearance 질의·프로필별 cache를 쓸지 비교합니다.
