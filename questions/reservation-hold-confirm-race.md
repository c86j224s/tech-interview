# 좌석을 보류한 뒤 결제를 확정합니다. 보류 만료와 늦은 결제 성공이 겹칠 때 어떤 전이를 허용하나요?

## 구두 답변

보류 만료와 결제 확정 중 어느 전이가 이길지 현재 상태·version을 조건으로 원자 결정합니다. 만료 뒤 좌석을 다른 사용자에게 줬다면 늦은 결제 성공을 그대로 좌석 확정으로 바꾸면 초과 판매가 됩니다.

결제 성공이 늦게 확인되면 환불·다시 예약·수동 확인 등 별도 조정 상태로 보냅니다. 자동 보상도 멱등 키와 승인 범위가 필요합니다. timer가 늦게 실행돼도 변경 요청 시 실제 만료 조건을 확인하며 원장과 사용자 상태를 대조합니다.
