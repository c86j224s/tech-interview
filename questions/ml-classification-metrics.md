# 양성 사례가 매우 드문 분류기에서 정확도가 99%입니다. 이 숫자만으로 모델이 좋은지 판단하지 않으려면 무엇을 함께 봐야 하나요?

## 구두 답변

정확도(accuracy)는 전체 예측 중 맞힌 비율입니다. 양성 사례가 1%인 사기 탐지에서 모든 사례를 음성이라고 예측해도 정확도는 99%가 됩니다. 하지만 이 모델은 사기를 하나도 잡지 못하므로, 클래스 비율이 크게 치우친 문제에서는 정확도를 단독 기준으로 쓰면 안 됩니다. 먼저 실제 양성을 양성으로 맞힌 참양성, 양성이라고 했지만 틀린 거짓양성, 놓친 거짓음성을 세어 혼동 행렬을 만듭니다.

정밀도(precision)는 양성이라고 판정한 것 중 실제 양성의 비율이고, 재현율(recall)은 실제 양성 중 모델이 찾아낸 비율입니다. 스팸 필터에서 정상 메일을 스팸으로 보내는 비용이 크면 정밀도를 중시할 수 있고, 위험 질환의 1차 선별처럼 놓치는 비용이 크면 재현율을 우선할 수 있습니다. 둘은 판정 임계값을 바꾸면서 서로 반대 방향으로 움직이는 경우가 많으므로, 하나만 높다고 좋은 분류기라고 말할 수 없습니다.

모델이 내놓은 확률 점수와 최종 양성·음성 판정은 다릅니다. 임계값을 낮추면 더 많이 잡아 재현율이 올라갈 수 있지만 거짓 경보와 후속 처리 비용이 늘어납니다. 반대로 임계값을 높이면 정밀도는 좋아질 수 있어도 놓치는 양성이 늘 수 있습니다. 운영 비용을 금액이나 처리 시간으로 추정하고 검증 데이터에서 임계값을 정한 뒤, 테스트 데이터에서 고정된 임계값으로 평가해야 합니다.

분류기 비교에는 클래스별 정밀도·재현율, 필요하면 두 값의 균형을 요약한 F1과 임계값 전반의 PR 곡선을 함께 봅니다. ROC-AUC가 유용한 경우도 있지만 희소한 양성 문제에서는 실제 운영 양성 비율과 비용을 반영하는 PR 관점이 더 직접적일 수 있습니다. 또한 양성 확률을 0.9 근처로 예측한 사례들 중 실제 양성의 비율이 약 90%인지 확률 보정(calibration)을 확인하면 자동 차단과 사람 검토의 경계를 정하는 데 도움이 됩니다. 어떤 지표를 선택할지는 클래스 비율과 오류 비용을 먼저 정한 뒤 결정하겠습니다.

## 득점 포인트

- 희소한 양성에서 전부 음성으로 예측해도 정확도가 높아지는 반례를 제시한다.
- 정밀도와 재현율을 각각 양성 예측 기준과 실제 양성 기준으로 정확히 정의한다.
- 임계값을 오류 비용에 맞춰 검증에서 정하고 테스트에서는 고정해 평가한다.

## 감점 포인트

- 정확도 99%만 보고 불균형 분류기가 실무에 충분하다고 결론 내린다.
- 정밀도를 실제 양성 중 찾은 비율로, 재현율을 양성 예측 중 맞은 비율로 뒤바꾼다.
- 테스트 데이터에서 비용에 맞는 임계값을 계속 조정하면서 공정한 성능이라고 말한다.

## 더 파고들 거리

- 오탐과 미탐의 실제 비용이 비대칭일 때 임계값과 후속 검토의 처리량을 어떻게 최적화할지 설명해 보세요.
- PR-AUC와 ROC-AUC가 희소 양성에서 다르게 읽힐 수 있는 이유를 예시로 비교해 보세요.
- 확률 보정 곡선과 임계값별 혼동 행렬을 이용해 자동 판정과 사람 검토를 나눠 보세요.
