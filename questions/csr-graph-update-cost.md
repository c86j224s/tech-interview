# 희소 그래프를 CSR로 저장합니다. 연속 순회의 이점과 간선 삽입·삭제의 재구성 비용은 무엇인가요?

## 구두 답변

CSR은 정점별 시작 offset과 연속 간선 배열로 이웃을 저장해 포인터·할당을 줄이고 순회 locality를 높일 수 있습니다. 중간 간선 삽입은 배열 이동과 뒤 offset 갱신이 필요해 동적 갱신에 불리할 수 있습니다.

변경을 별도 delta 구조에 모아 주기적으로 재구축하는 절충은 읽기 병합·버전 비용을 추가합니다. 방향·중복·자기 간선 의미를 유지하고 snapshot 교체 뒤 독자 수명을 보호합니다. 정적·갱신 혼합 workload에서 메모리·순회·재구축을 비교합니다.
