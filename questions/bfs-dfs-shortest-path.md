# 모든 이동 비용이 같은 그래프에서 가장 적은 이동 횟수를 찾으려 합니다. BFS와 DFS 중 무엇이 맞나요?

## 구두 답변

BFS는 출발점에서 가까운 단계부터 방문하므로 모든 간선 비용이 같을 때 최소 이동 횟수를 찾는 데 적합합니다. DFS는 한 경로를 깊게 따라가므로 먼저 목적지에 도착했다고 가장 짧은 경로인 것은 아닙니다.

BFS는 큐에 시작점을 넣고 이웃을 다음 단계로 추가합니다. 처음 발견할 때 방문 표시를 하면 같은 정점이 여러 번 큐에 쌓이는 것을 줄일 수 있습니다. 부모 정점을 함께 기록하면 목적지에서 거꾸로 따라가 경로를 복원할 수 있습니다. 간선 비용이 서로 다르면 단계가 적어도 더 비쌀 수 있으므로 Dijkstra 같은 다른 기준이 필요합니다.

DFS는 연결성 확인이나 모든 경로를 탐색하는 백트래킹, 위상 관계를 다루는 작업에 유용합니다. 재귀 DFS는 긴 사슬에서 호출 스택이 넘칠 수 있어 명시적인 스택을 사용할 수 있습니다. 저는 알고리즘 이름보다 최소화할 값이 간선 수인지 총비용인지 먼저 정하겠습니다. 테스트는 순환, 여러 최단 경로, 도달 불가능한 정점과 긴 경로를 포함합니다.

## 득점 포인트

- 동일 비용 조건과 BFS 단계 순서를 연결한다.
- 방문 표시와 부모 기록을 설명한다.
- DFS의 목적과 스택 한계를 구분한다.

## 감점 포인트

- DFS의 첫 도착도 최단이라고 말한다.
- 가중치가 다른데 BFS로 최소 비용을 보장한다.
- 순환 그래프에서 방문 처리를 생략한다.

## 더 파고들 거리

- 여러 시작점의 가장 가까운 거리를 찾으려면 BFS를 어떻게 시작할까요?
- 0과 1 비용만 있는 그래프에서는 어떤 변형이 가능할까요?
- 양방향 BFS는 어떤 조건에서 탐색량을 줄일까요?
