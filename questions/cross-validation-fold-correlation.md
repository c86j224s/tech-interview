# 교차 검증 점수의 평균과 분산을 봅니다. 겹치는 학습 자료와 그룹 의존성은 불확실성 해석에 어떤 영향을 주나요?

## 구두 답변

fold별 학습 집합이 겹치므로 점수들이 완전히 독립 표본이라고 가정하면 불확실성을 과소평가할 수 있습니다. 사용자·기관·시간 같은 그룹 의존도 분할에 반영합니다.

평균뿐 아니라 fold별 편차·최악 집단·표본 수를 보고합니다. 전처리는 각 학습 fold에서 fit하고 최종 holdout을 따로 둡니다. 유한한 반복 점수의 작은 차이를 보편적 우열로 과장하지 않습니다.
