# 메모리 총 여유는 충분한데 큰 연속 영역 할당이 실패할 수 있나요?

## 구두 답변

가능하지만 어떤 계층에서 연속성을 요구하는지 먼저 구분해야 합니다. 가변 크기 할당 영역의 빈 구간이 흩어져 있으면 합계는 충분해도 큰 연속 블록이 없을 수 있습니다. 이것을 외부 단편화라고 하고, 할당받은 블록 안의 남는 공간은 내부 단편화라고 합니다.

일반 사용자 프로그램의 연속 가상 메모리가 반드시 연속 물리 메모리를 요구하는 것은 아닙니다. 페이징이 둘을 분리할 수 있기 때문입니다. 반면 장치나 대형 페이지 등 실제 물리 연속성을 요구하는 경로는 다른 제약을 가질 수 있습니다. 단순히 RAM이 남는다는 숫자만으로 모든 할당을 설명할 수는 없습니다.

저는 실패한 할당의 크기·주소 공간·할당자와 프로세스 한도를 확인하겠습니다. 비슷한 크기의 객체를 풀로 관리하면 일부 단편화를 줄일 수 있지만 사용하지 않는 공간을 더 오래 보유할 수 있습니다. 조각난 물리 페이지를 압축하는 비용도 지연에 영향을 줍니다. 테스트는 다양한 크기의 생성·해제를 반복하며 살아 있는 객체량, 할당자 보유량과 큰 할당 성공률을 따로 보겠습니다.

## 득점 포인트

- 내부·외부 단편화를 구분한다.
- 가상·물리 연속성의 계층을 명시한다.
- 풀과 압축의 비용을 함께 본다.

## 감점 포인트

- 총 여유만 있으면 모든 연속 할당이 가능하다고 말한다.
- 가상 연속 주소는 항상 물리적으로도 연속이라고 말한다.
- 풀은 단편화와 메모리 낭비를 모두 없앤다고 말한다.
