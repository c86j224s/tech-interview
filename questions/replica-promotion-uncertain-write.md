# 원본이 성공한 쓰기를 replica가 적용하기 전에 승격됐습니다. 사용자 재시도와 누락 대사는 어떻게 처리하나요?

## 구두 답변

비동기 복제에서는 성공 응답된 쓰기가 새 원본에 없을 수 있습니다. 클라이언트 성공 기록·요청 ID·복제 위치와 새 원장을 대조하고 불확정 결과를 명시합니다.

같은 요청을 재실행할 때 중복 방지 기록도 함께 손실됐을 수 있어 외부 결제사·내구 원장 조회가 필요할 수 있습니다. 모든 손실을 자동 복구한다고 약속하지 않습니다. 승격 대상·RPO·동기 복제 비용과 사용자 재시도 정책을 장애 시험으로 확인합니다.

## 득점 포인트

- 비동기 복제에서는 성공 응답된 쓰기가 새 원본에 없을 수 있습니다. 클라이언트 성공 기록·요청 ID·복제 위치와 새 원장을 대조하고 불확정 결과를 명시합니다.
- 승격 대상·RPO·동기 복제 비용과 사용자 재시도 정책을 장애 시험으로 확인합니다.
