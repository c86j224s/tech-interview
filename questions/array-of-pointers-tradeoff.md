# 큰 객체 대신 포인터를 배열에 저장하면 삽입 이동량은 줄어듭니다. 추가되는 캐시·소유권 비용은 무엇인가요?

## 구두 답변

포인터 배열은 중간 삽입 때 큰 객체 대신 작은 포인터만 이동시킵니다. 하지만 실제 객체를 읽을 때 간접 참조와 흩어진 할당으로 cache miss가 늘 수 있고, 포인터가 가리키는 객체 수명도 별도로 관리해야 합니다.

순차 전체 스캔·일부 필드 접근·삽입 위치 탐색을 나눠 측정합니다. 주소가 안정적이어도 배열 인덱스는 삽입·삭제로 바뀔 수 있습니다. 소유 포인터와 관찰 핸들을 구분하고 삭제 뒤 남은 참조를 안전하게 무효화합니다.

## 득점 포인트

- 포인터 배열은 중간 삽입 때 큰 객체 대신 작은 포인터만 이동시킵니다. 하지만 실제 객체를 읽을 때 간접 참조와 흩어진 할당으로 cache miss가 늘 수 있고, 포인터가 가리키는 객체 수명도 별도로 관리해야 합니다.
