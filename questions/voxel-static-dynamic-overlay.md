# 정적 고체와 동적 문·객체 점유를 합칩니다. 우선순위·독립 벽·버전의 의미를 어떻게 보존하나요?

## 구두 답변

정적 지형·문 자체 형상·동적 객체 점유를 별도 의미로 유지하고 질의 때 현재 버전과 에이전트 규칙으로 합칩니다. 문이 열려도 문틀·뒤의 독립 벽이 사라져서는 안 됩니다.

동적 객체 제거와 정적 고체 삭제를 같은 비트로 혼합하지 않습니다. 질의 결과에 미로딩·반경 부족·동적 차단 같은 원인을 제공할 수 있습니다. 동시 전환과 프로필별 충돌·경로 일치를 시험합니다.
