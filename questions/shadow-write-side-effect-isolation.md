# 새 시스템에 shadow traffic을 보냅니다. 실제 결제·메일·쓰기 효과를 중복 실행하지 않고 무엇을 비교하나요?

## 구두 답변

shadow 비교는 실제 쓰기·메일·결제를 두 번 실행하지 않는 격리 경로가 필요합니다. 읽기 전용·가상 sink·독립 데이터로 동작을 관찰하고 정상 트래픽의 권위는 한쪽에 둡니다.
