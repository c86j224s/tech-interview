# 짧은 작업을 배치로 묶어 전환 비용을 줄입니다. 긴 배치가 다른 요청을 굶기지 않게 어떤 시간 예산을 두나요?

## 구두 답변

배치 항목 수뿐 아니라 실제 실행 시간과 가장 오래 기다린 작업을 기준으로 양보 지점을 둡니다. 항목별 비용이 다르면 같은 100개 배치라도 점유 시간이 크게 달라집니다.

한 번에 최대 개수·시간 중 먼저 닿는 조건을 적용하고 나머지를 다음 라운드로 넘깁니다. 비선점 작업 하나가 이미 길면 배치 상한만으로 응답 상한을 보장하지 못해 분할·별도 worker가 필요합니다. throughput·p99·기아·문맥 교환 비용을 같은 부하에서 비교합니다.

- 배치 항목 수뿐 아니라 실제 실행 시간과 가장 오래 기다린 작업을 기준으로 양보 지점을 둡니다. 항목별 비용이 다르면 같은 100개 배치라도 점유 시간이 크게 달라집니다.
