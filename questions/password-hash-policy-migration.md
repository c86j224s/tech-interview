# 비밀번호 해시 정책을 강화했습니다. 로그인하지 않는 오래된 계정은 어떤 재설정·만료 절차로 전환하나요?

## 구두 답변

새 hash 정책은 다음 정상 로그인에서 원문 비밀번호를 얻을 때 재해시할 수 있지만 장기 미접속 계정은 그 기회가 없습니다. 기존 위험·보관 기간에 따라 재설정·만료·접근 제한 정책을 둡니다.

옛 hash에서 새 hash를 직접 만들어 원문 보안을 동일하게 강화할 수 있다고 가정하지 않습니다. migration version·성공 여부·rate limit을 관리합니다. 사용자 복구 경로가 기본 인증보다 약해지지 않게 확인합니다.
