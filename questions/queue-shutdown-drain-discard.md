# 작업 큐 종료에서 전부 처리하는 정책과 남은 작업을 버리는 정책은 대기 조건과 결과 처리가 어떻게 다른가요?

## 구두 답변

drain 정책은 새 수락을 막고 남은 큐와 실행 작업을 끝냅니다. 즉시 중단 정책은 대기 작업을 취소·재전달 대상으로 만들고 실행 중 효과를 별도로 정리합니다. 두 정책의 predicate와 완료 조건을 섞지 않습니다.

대기자는 stopping 또는 작업 존재를 확인하고, stopping일 때 큐를 처리할지 반환할지 명시합니다. 여러 worker를 깨우고 새 자식 등록 경쟁도 막습니다. 버린 작업이 원본 큐·로그에서 복구 가능한지 확인하고 ACK·완료 표시를 먼저 전진시키지 않습니다.

## 득점 포인트

- drain 정책은 새 수락을 막고 남은 큐와 실행 작업을 끝냅니다. 즉시 중단 정책은 대기 작업을 취소·재전달 대상으로 만들고 실행 중 효과를 별도로 정리합니다. 두 정책의 predicate와 완료 조건을 섞지 않습니다.
- 버린 작업이 원본 큐·로그에서 복구 가능한지 확인하고 ACK·완료 표시를 먼저 전진시키지 않습니다.

## 감점 포인트
