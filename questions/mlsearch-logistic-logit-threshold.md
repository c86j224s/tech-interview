# 양성 확률 0.5가 아닌 임계값을 쓸 때 로짓과 판정은 어떻게 나누나요?

## 구두 답변
모델은 먼저 `z=wᵀx+b`라는 연속 로짓을 만들고, 필요할 때 `p=sigmoid(z)`로 표현한 뒤 정책이 판정을 정합니다. 확률 임계값 `t`와 동등한 로짓 경계는 `log(t/(1-t))`입니다. 예를 들어 `t=.2`이면 경계가 약 `-1.386`이므로 `z=-1.2`는 양성 행동, `z=-2`는 음성 행동입니다. 이는 모델을 재학습한 것이 아니라 같은 score에 더 민감한 행동 경계를 적용한 것입니다. 미탐 비용이나 검토 용량을 반영할 threshold는 train loss가 아니라 validation에서 TP·FP·FN·TN과 비용을 비교해 고르고, test에서는 고정합니다. 확률이 보정되지 않았다면 .8을 실제 양성 확률 80%로 읽지 말고 calibration을 별도로 확인합니다.


실무적으로는 threshold를 고르는 자료의 분포도 확인해야 합니다. 예를 들어 validation에서 `z=-2,-1.5,-1,0,1`이고 정답이 `[0,1,1,0,1]`이라면 .5 경계는 `z≥0` 두 건만 양성으로 잡지만 .2 경계는 `z≥-1.386`인 세 건을 잡습니다. 추가된 `z=-1` 사례가 양성이면 FN 하나를 줄이고, 음성이면 FP 하나와 검토 비용을 늘립니다. 여기서 threshold를 낮춘 결과를 “모델이 더 정확해졌다”고 말하면 안 되고, 같은 ranking에 정책 비용을 적용한 결과라고 말해야 합니다. 모델을 바꿔 score 분포가 이동하면 예전 경계를 재사용하지 않고 validation에서 다시 고릅니다.

운영 큐가 하루 100건으로 제한되면 threshold를 낮춰 양성을 많이 잡는 대신 queue가 넘치는 지점을 찾고, 그 안에서 FN 비용과 FP 처리 비용을 비교합니다. score가 같은 두 사례를 임의로 나누지 않도록 tie 규칙과 경계 포함 여부(`≥`인지 `> `인지)도 artifact에 고정합니다.
## 득점 포인트
- sigmoid의 단조성을 이용해 확률 경계를 로짓 경계로 변환하고 `t=.2→-1.386`의 중간 계산을 제시합니다.
- threshold는 학습 파라미터가 아니라 오류 비용·검토량을 반영하는 validation 정책이라고 구분합니다.
- 동일 모델의 score를 고정한 채 경계만 바꾸는 실험과 모델을 다시 학습하는 실험을 분리합니다.

## 감점 포인트
- 0.5가 모든 데이터에서 최적이거나 p=.8이 자동으로 80% 빈도를 뜻한다고 말합니다.
- test를 보며 threshold를 재선택하거나 threshold 변경을 모델 성능 학습으로 설명합니다.
- class weight나 sampling으로 바뀐 score에도 기존 경계를 그대로 적용한다고 단정합니다.

## 더 파고들 거리
- 양성 비용과 음성 비용으로 기대비용을 계산해 threshold를 정하는 방법을 비교해 보세요.
- calibration이 깨진 score에서 로짓 순위와 확률 해석을 각각 어떻게 검증할지 설명해 보세요.
