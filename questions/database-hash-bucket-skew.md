# DB 해시 인덱스에서 특정 값 집단만 느립니다. 버킷 충돌·편중·재구성 비용을 어떻게 확인하나요?

## 구두 답변

동등 조건의 빈도·키 분포·버킷 길이와 실제 테이블 접근을 나눠 봅니다. 해시값이 같은 후보도 원래 키를 비교해야 하므로 큰 충돌 집합은 선형에 가까운 검사량을 만들 수 있습니다.

평균 lookup만 보지 않고 편중 키·의도적인 충돌·버킷 확장 시점을 측정합니다. 제품이 지원하는 해시 인덱스의 저장 방식과 연산 범위를 확인하고 B-tree 같은 대안과 쓰기 비용도 비교합니다. 해시의 평균 O(1)을 DB 전체 질의의 상수 지연으로 표현하지 않습니다.
