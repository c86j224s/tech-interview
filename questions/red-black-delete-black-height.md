# Red-Black Tree의 검정 노드를 삭제합니다. 삽입과 다른 검정 높이 복구는 어떤 불변식을 유지하나요?

## 구두 답변

검정 노드를 제거하면 일부 경로의 검정 수가 하나 줄 수 있어 형제·조카 색과 회전·재색칠로 복구합니다. 빨간 노드 삽입의 연속 빨강 문제와 다른 경우를 처리합니다.

BST 순서·root/NIL 색·각 경로 검정 높이·부모 포인터를 매 연산 뒤 검사합니다. 교과서 double-black 표현은 불변식 설명 수단이며 실제 구현 상태와 맞춰야 합니다. 삭제 노드 수명도 별도 보호합니다.
