# 외부 키를 받는 해시 테이블에서 충돌 공격을 줄이려 합니다. 해시 시드와 입력 제한이 각각 무엇을 보호하나요?

## 구두 답변

예측하기 어려운 hash seed는 공격자가 많은 충돌 키를 미리 만드는 난도를 높일 수 있지만 모든 최악 입력·큰 요청을 제거하지 않습니다. 키 길이·항목 수·CPU·메모리 제한과 검증된 자료구조를 함께 사용합니다.

재현 테스트용 seed와 외부에 노출되는 안정 ID의 hash는 목적이 다릅니다. 프로세스별 random hash를 분산 샤드 키로 쓰지 않습니다. 허가된 격리 환경에서 충돌·긴 문자열·재해시 p99와 정상 throughput을 비교합니다.
