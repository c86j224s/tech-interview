# 훈련 정확도는 계속 오르는데 검증 정확도는 떨어집니다. 과적합을 어떻게 알아보고 보지 않은 데이터의 일반화를 개선하나요?

## 구두 답변

과적합(overfitting)은 모델이 훈련 데이터의 우연한 잡음이나 개별 사례까지 외워 훈련 성능은 높지만 새로운 데이터 성능은 낮아지는 현상입니다. 전형적인 신호는 학습이 진행될수록 훈련 손실은 줄고 검증 손실은 어느 시점부터 늘어나는 것입니다. 다만 검증 점수 한 번의 하락만으로 단정하지 말고, 여러 시드와 접기에서 같은 패턴인지, 검증 데이터의 분포와 품질이 훈련과 맞는지 먼저 확인해야 합니다.

일반화(generalization)는 학습에 사용하지 않은, 같은 문제 분포의 입력에서도 유용한 예측을 하는 능력입니다. 모델이 크고 데이터가 적거나, 특징이 누수되었거나, 훈련 자료가 특정 사례에 치우치면 일반화가 약해집니다. 모델 용량을 줄이는 것은 표현력을 낮춰 분산을 줄일 수 있지만, 실제로 필요한 패턴까지 못 배워 과소적합을 만들 수 있습니다. 따라서 훈련·검증 곡선과 실제 오류 사례를 함께 봐야 합니다.

대응은 데이터와 모델 양쪽에서 합니다. 더 다양한 훈련 데이터를 확보하고 중복·라벨 오류를 정리하며, 이미지라면 의미를 보존하는 증강을 적용할 수 있습니다. 모델 복잡도나 학습 시간을 제한하고, 가중치에 비용을 주는 정규화와 검증 손실이 악화되기 전 멈추는 조기 종료를 사용할 수도 있습니다. 드롭아웃 같은 기법은 특정 상황에서 도움이 되지만 무조건 추가한다고 일반화가 보장되지는 않으며, 검증 세트로 강도를 선택해야 합니다.

중요한 점은 훈련 성능을 더 올리는 것이 목표가 아니라 배포 시 만날 데이터의 오류를 줄이는 것입니다. 검증 세트를 반복해 보며 기법을 고르면 검증에도 과적합할 수 있으므로 최종 테스트는 끝까지 보존합니다. 훈련과 검증의 격차가 크면 정규화나 데이터 확대를 먼저 검토하고, 둘 다 낮으면 모델 용량·특징·라벨 자체를 점검하는 식으로 조건에 따라 대응하겠습니다.

## 득점 포인트

- 훈련 개선과 검증 악화를 과적합의 신호로 설명하고 단일 점수만으로 단정하지 않는다.
- 일반화를 보지 않은 같은 분포의 데이터에서의 성능으로 정의하고 데이터·모델 원인을 나눈다.
- 격차가 클 때 정규화·데이터 확대·조기 종료를, 둘 다 낮을 때 용량과 특징을 점검하는 기준을 제시한다.

## 감점 포인트

- 훈련 정확도가 높으면 모델이 일반화됐다고 판단한다.
- 모델을 작게 만들면 항상 해결되며 과소적합 가능성은 없다고 말한다.
- 검증 세트에 맞춰 기법을 반복 선택하면서도 최종 성능을 독립적으로 추정했다고 주장한다.

## 더 파고들 거리

- 데이터 증강이 라벨 의미를 바꿀 수 있는 도메인에서 허용 변환을 어떻게 검증할지 정해 보세요.
