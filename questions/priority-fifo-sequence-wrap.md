# 동점 작업에 삽입 순번을 붙입니다. 순번 overflow와 재시작 뒤에도 FIFO를 유지하려면 어떻게 하나요?

## 구두 답변

순번이 wrap되면 단순 정수 대소가 삽입 순서를 거꾸로 볼 수 있습니다. 충분한 폭·epoch·재시작 후 이어지는 내구 순번 또는 bounded window 비교를 계약으로 정합니다.

큐 안에 옛·새 세대가 동시에 존재할 수 있는지 확인합니다. ID를 임의 재사용하면 오래된 취소가 새 작업을 지울 수 있습니다. 동점 FIFO와 우선순위 낮은 작업의 기아는 다른 문제입니다.
