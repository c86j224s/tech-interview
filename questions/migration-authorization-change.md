# 사용자 데이터 이전 중 권한이나 대표 계정이 바뀝니다. 복사 완료와 접근 공개는 어떤 현재 상태를 다시 검사하나요?

## 구두 답변

복사 시작 때 권한이 있었다고 완료 공개 시점에도 같다고 가정하지 않습니다. 현재 계정·대표 매핑·인가 version을 재검사하고 달라지면 게시를 보류하거나 새 권위로 재조정합니다.

원본 값 이동과 로그인 자격 연결은 다른 작업입니다. 늦은 옛 worker가 새 세대 데이터를 덮지 못하게 저장 조건을 둡니다. 병합·철회·동시 접속·부분 복사에서 권리와 제한을 대조합니다.
