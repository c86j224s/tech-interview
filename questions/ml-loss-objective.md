# 모델의 학습 오차는 줄었는데 실제 성능 지표는 좋아지지 않습니다. 손실 함수와 학습 목적은 평가 지표와 어떻게 다른가요?

## 구두 답변

손실 함수(loss function)는 한 예에서 정답과 모델 예측이 얼마나 다른지를 수치로 나타내는 함수입니다. 예를 들어 회귀에서는 예측값과 실제값의 차이를 크게 틀린 사례에 더 크게 벌주는 손실을 쓸 수 있고, 분류에서는 정답 클래스에 높은 확률을 주도록 유도하는 손실을 쓸 수 있습니다. 학습은 훈련 데이터 전체의 손실을 모아 모델 파라미터를 조정하는 과정이므로, 손실이 작아지는 방향이 기본 목표입니다.

학습 목적(objective)은 단순한 예측 오차에 정규화 항이나 가중치를 더한, 실제 최적화 대상 전체를 뜻합니다. 정규화는 모델이 훈련 자료를 외우는 것을 억제하기 위해 복잡한 파라미터에 비용을 부과하는 방식입니다. 따라서 로그에 표시한 순수 예측 손실과 최적화기가 최소화하는 목적 함수가 서로 다를 수 있습니다. 무엇을 줄이는지와 어떤 데이터 분할에서 계산하는지를 구분해야 학습 곡선을 올바르게 읽을 수 있습니다.

평가 지표(metric)는 제품이나 문제의 성공을 판단하기 위한 측정값입니다. 추천에서는 클릭률, 회귀에서는 허용 오차 안의 비율, 불균형 분류에서는 재현율이나 정밀도가 더 중요할 수 있습니다. 최적화하기 쉬운 손실과 운영상 중요한 지표가 같은 숫자일 필요는 없습니다. 예컨대 평균 제곱 오차를 줄여도 큰 오류 몇 건이나 특정 임계값 뒤의 분류 결과가 개선된다는 보장은 없습니다.

그래서 손실은 학습 신호로, 목적 함수는 파라미터를 실제로 움직이는 기준으로, 평가지표는 보지 않은 데이터에서 의사결정 품질을 확인하는 기준으로 설명하겠습니다. 훈련 손실만 내려가고 검증 지표가 정체되면 데이터 분할, 임계값, 손실과 지표의 불일치, 과적합을 차례로 점검합니다. 평가 지표를 손실로 바꾸는 선택은 미분 가능성, 안정성, 오탐·미탐이 초래하는 실제 비용을 함께 확인한 뒤 해야 하며, 숫자가 작다는 이유만으로 제품 목표가 달성됐다고 결론 내리면 안 됩니다.

## 득점 포인트

- 손실을 정답·예측의 예별 오차로 정의하고, 학습이 그 집계값을 줄이는 과정임을 설명한다.
- 정규화가 포함된 objective와 순수 예측 손실을 구분한다.
- 최적화하기 쉬운 손실과 운영 목적을 측정하는 평가 지표가 다를 수 있는 이유를 사례로 연결한다.

## 감점 포인트

- 손실 함수가 작으면 어떤 평가 지표도 반드시 좋아진다고 단정한다.
- 정규화 항까지 포함한 목적 함수와 로그의 예측 오차를 같은 값으로 해석한다.
- 분류 임계값과 오탐·미탐이 초래하는 실제 비용을 무시하고 손실 최소화만으로 배포 여부를 정한다.

## 더 파고들 거리

- 가중치가 있는 분류 손실이 소수 클래스의 재현율과 정밀도에 어떤 변화를 주는지 설명해 보세요.
- 미분하기 어려운 운영 지표를 직접 최적화하지 않고 대체 손실을 쓰는 이유를 비교해 보세요.
- 훈련·검증 곡선에서 예측 손실과 정규화 항을 따로 기록해 원인을 진단해 보세요.
