# 큰 보스와 작은 투사체의 공개 반경이 다릅니다. AOI 후보 검색에서 객체 크기와 수신 반경을 어떻게 반영하나요?

## 구두 답변

객체 중심만 인덱싱한다면 큰 형상의 공개 경계가 후보 검색 밖으로 뻗는 경우를 보완해야 합니다. 객체 AABB 다중 셀 등록이나 최대 반경 확장·계층 구조를 사용하고 최종 공개 정책을 따로 검사합니다.

큰 보스를 여러 셀에서 찾으면 ID·세대로 후보를 중복 제거합니다. 거리상 가깝더라도 다른 인스턴스·시야·권한이면 전송하지 않습니다. 작은·큰 객체와 셀 경계·순간이동의 전수 AOI 결과를 기준으로 포함 관계와 사용자별 송신량을 검증합니다.
