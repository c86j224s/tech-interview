# 추적 대상이 계속 움직입니다. 매 틱 재탐색하지 않으면서 경로 오차와 안전성을 어떻게 관리하나요?

## 구두 답변

목표 이동 거리·경로 유효성·재계산 비용을 기준으로 재탐색을 요청하고 NPC별 cooldown·전역 예산을 둡니다. 매 틱 전체 탐색 대신 현재 안전 구간을 따라가며 중요한 변화 때 갱신할 수 있습니다.

결과에 목표 세대·맵·에이전트 프로필을 붙여 늦은 계산을 거절합니다. 너무 긴 주기는 추적 오차·실패를 키우고 너무 짧으면 CPU·취소 잔존이 늘어납니다. 실제 이동 직전 충돌 검사는 재탐색 간격과 별도로 유지합니다.
