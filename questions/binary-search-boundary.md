# 정렬된 배열에서 target 이상인 첫 위치를 찾습니다. 이진 탐색의 경계 오류를 어떻게 피하나요?

## 구두 답변

먼저 찾는 것이 같은 값 하나인지, target 이상인 첫 위치인지 정확히 정해야 합니다. 중복 값이 있는 배열에서는 일치하는 아무 위치를 찾는 것과 경계를 찾는 것이 다릅니다. 저는 반열린 구간처럼 범위 규칙을 하나로 정하고 반복 내내 유지하겠습니다.

다음은 Python의 설명용 구현입니다. 입력 a는 오름차순으로 정렬돼 있다고 가정합니다.

```python
def lower_bound(a, target):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

mid가 target보다 작으면 그 위치까지 답이 될 수 없으므로 버리고, 그렇지 않으면 mid도 답 후보로 남깁니다. 반환값은 배열 길이일 수도 있어 사용 전에 범위를 확인해야 합니다. 테스트는 빈 배열, 모두 작은 값, 모두 큰 값, 중복과 끝점 일치를 포함합니다. 같은 원리로 답이 가능해지는 경계를 찾는 문제도 풀 수 있지만 조건이 단조적인지 먼저 확인해야 합니다.

## 득점 포인트

- 원소 검색과 경계 검색을 구분한다.
- 탐색 구간과 후보 보존을 설명한다.
- 길이 반환과 단조 조건을 검증한다.

## 감점 포인트

- 일치하는 즉시 반환해 첫 위치라고 한다.
- 빈 배열과 길이 반환을 처리하지 않는다.
- 단조하지 않은 조건에도 이진 탐색을 적용한다.
