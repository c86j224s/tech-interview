# 과거 패킷 로그 재생과 상태 기반 더미 클라이언트 테스트는 각각 어떤 오류를 찾고 놓치나요?

## 구두 답변

패킷 재생은 실제 wire 형식과 과거 순서의 회귀를 재현하기 좋지만 토큰·시각·ID가 바뀌면 그대로 유효하지 않을 수 있습니다. 상태 시나리오는 현재 응답을 읽고 다음 요청을 만들어 더 유연하지만 같은 client 구현 오류를 공유할 수 있습니다.

wire 경계는 독립 golden packet으로, 업무 흐름은 상태 기반 client로 검사합니다. 원문 트래픽의 개인정보·외부 효과를 격리합니다. 한 실패를 줄일 때는 이벤트 ID와 필수 선후를 보존하고 단순 시간 sleep에 의존하지 않습니다.
