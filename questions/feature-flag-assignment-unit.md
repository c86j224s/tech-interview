# 사용자별 또는 조직별로 새 기능을 배정합니다. 공유 데이터와 실험 독립성에 어떤 차이가 생기나요?

## 구두 답변

개별 사용자가 독립 데이터를 쓰면 사용자 배정이 단순하지만 조직 구성원이 같은 자원을 공유하면 혼합 규칙이 충돌할 수 있어 조직 단위 배정이 적합할 수 있습니다. 실험 표본의 독립 단위도 그 배정과 맞춰야 합니다.

안정 해시·배정 version을 사용하고 실제 노출을 기록합니다. 비율을 늘릴 때 같은 대상이 불필요하게 오가게 하지 않습니다. 조직 크기 편중·네트워크 효과·공유 데이터 호환을 검증하고 사용자 수만으로 독립 표본 수를 과장하지 않습니다.

## 득점 포인트

- 개별 사용자가 독립 데이터를 쓰면 사용자 배정이 단순하지만 조직 구성원이 같은 자원을 공유하면 혼합 규칙이 충돌할 수 있어 조직 단위 배정이 적합할 수 있습니다. 실험 표본의 독립 단위도 그 배정과 맞춰야 합니다.
- 조직 크기 편중·네트워크 효과·공유 데이터 호환을 검증하고 사용자 수만으로 독립 표본 수를 과장하지 않습니다.
