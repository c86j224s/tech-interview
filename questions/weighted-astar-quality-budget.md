# Weighted A*의 휴리스틱 가중치를 높이려 합니다. 탐색 시간과 경로 비용의 손실을 어떤 전제에서 비교하나요?

## 구두 답변

가중치 w로 h를 키우면 목표 방향 탐색을 강화하지만 일반 A*의 최적성 보장은 바뀝니다. 허용적 휴리스틱과 적절한 종료·재오픈 규칙 등에서 알려진 비용 상한을 적용할 수 있는지 구현을 확인해야 합니다.

기준 Dijkstra·A*의 최적 비용과 반환 경로 비용, 노드 수·CPU·메모리를 함께 측정합니다. 단순히 timeout 때 아무 후보를 반환하면 weighted bound까지 보장되는 것은 아닙니다. 정확·근사·미완료 상태를 호출자에게 구분해 전달합니다.
