# 불변 트리의 리프 하나를 수정합니다. 어느 경로만 복사하고 어떤 하위 노드를 공유할 수 있나요?

## 구두 답변

리프까지의 변경 경로 노드를 새로 만들고 바뀌지 않은 하위 트리를 공유합니다. 공유 노드가 불변이면 옛 root를 읽는 독자가 새 변경에 오염되지 않습니다.

root를 원자·안전하게 게시하고 이전 독자 수명을 유지합니다. 트리 균형·분기 수·보관 버전 수에 따른 할당을 측정하며 가변 자식 하나가 전체 불변성을 깨지 않는지 검사합니다.

## 득점 포인트

- 리프까지의 변경 경로 노드를 새로 만들고 바뀌지 않은 하위 트리를 공유합니다. 공유 노드가 불변이면 옛 root를 읽는 독자가 새 변경에 오염되지 않습니다.
- 트리 균형·분기 수·보관 버전 수에 따른 할당을 측정하며 가변 자식 하나가 전체 불변성을 깨지 않는지 검사합니다.
