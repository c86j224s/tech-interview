# 실제 백업으로 복구 훈련을 합니다. 개인정보와 옛 outbox의 외부 효과를 어떻게 격리하나요?

## 구두 답변

복원 환경은 운영의 메일·결제·웹훅 endpoint와 자격을 사용하지 않게 격리합니다. 실제 백업에는 개인정보와 과거 미처리 outbox가 있으므로 접근권한·암호화 키·로그 수집도 제한해야 합니다.

DB 복원 뒤 자동 시작되는 consumer·scheduler를 먼저 차단하고 합성 sink로 전환합니다. 데이터 무결성·권한·읽기·제한된 쓰기를 검증한 뒤 훈련 결과를 기록합니다. 비식별 데이터 시험과 실제 백업 파일의 복구 가능성 검사는 목적이 달라 둘 다 필요한 범위를 정합니다.

## 득점 포인트

- 복원 환경은 운영의 메일·결제·웹훅 endpoint와 자격을 사용하지 않게 격리합니다. 실제 백업에는 개인정보와 과거 미처리 outbox가 있으므로 접근권한·암호화 키·로그 수집도 제한해야 합니다.
