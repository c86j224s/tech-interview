# 실행 중 바꿀 수 없는 연결·메모리 설정을 수정했습니다. 재시작과 진행 요청 정리는 어떻게 연결하나요?

## 구두 답변

새 설정을 검증해 배포 버전에 연결하고 새 프로세스가 그 설정으로 준비된 뒤 기존 프로세스를 drain합니다. 값 저장 성공과 실행 적용 완료를 구분해야 합니다.

연결 수 상한을 낮춰도 이미 빌려 준 연결을 안전 없이 강제 반환할 수 없습니다. 신규 수락을 제한하고 실제 완료 뒤 줄입니다. 혼합 버전에서 프로토콜·데이터가 호환되는지, 되돌릴 때 새 상태를 옛 코드가 읽을 수 있는지 검사합니다.

## 득점 포인트

- 새 설정을 검증해 배포 버전에 연결하고 새 프로세스가 그 설정으로 준비된 뒤 기존 프로세스를 drain합니다. 값 저장 성공과 실행 적용 완료를 구분해야 합니다.
- 혼합 버전에서 프로토콜·데이터가 호환되는지, 되돌릴 때 새 상태를 옛 코드가 읽을 수 있는지 검사합니다.
