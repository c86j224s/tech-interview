# 작업 실행 시간 예측이 자주 틀립니다. 스케줄러의 예상 비용과 실제 사용량을 어떻게 보정하나요?

## 구두 답변

예상 실행 시간은 실제 사용량을 관측하며 갱신하되 한 번의 긴 이상치로 모든 작업 비용을 바꾸지 않습니다. 작업 유형·입력 크기별 추정과 지수 이동 평균 등을 사용할 수 있지만 예측 오차를 인정해야 합니다.

너무 작게 예측한 작업이 자원을 독점하지 않게 실제 실행 budget과 양보·분할을 둡니다. 완료 건수 대신 CPU·연결 보유 시간을 함께 보고, 낮은 비용으로 신고한 사용자 입력을 그대로 믿지 않습니다. 계단 부하와 예측 실패에서 공정성과 p99를 비교합니다.

## 득점 포인트

- 예상 실행 시간은 실제 사용량을 관측하며 갱신하되 한 번의 긴 이상치로 모든 작업 비용을 바꾸지 않습니다. 작업 유형·입력 크기별 추정과 지수 이동 평균 등을 사용할 수 있지만 예측 오차를 인정해야 합니다.
- 계단 부하와 예측 실패에서 공정성과 p99를 비교합니다.

## 감점 포인트

- 다음 핵심 구분을 반대로 설명하거나 성립 조건을 생략한다: 예상 실행 시간은 실제 사용량을 관측하며 갱신하되 한 번의 긴 이상치로 모든 작업 비용을 바꾸지 않습니다.
