# 격자 경로 복원에서 부모 포인터 대신 방향만 저장하려 합니다. 가능한 이동 모델과 복원·메모리 비용은 무엇인가요?

## 구두 답변

정해진 이웃 이동만 있는 격자라면 부모 방향을 작은 코드로 저장하고 현재 셀에서 역방향으로 따라가 복원할 수 있습니다. 임의 포털·점프·다중 상태가 있으면 방향만으로 부모를 유일하게 정하지 못할 수 있습니다.

비용 갱신 때 방향도 함께 바꾸고 탐색 세대·맵 version을 유지합니다. 방향 코드의 유효 범위·시작 sentinel·사이클·최대 복원 길이를 검사합니다. 절약된 메모리와 변환 비용, 비동기 결과가 참조하는 배열 수명을 함께 평가합니다.
