# 지역 분할 중 좌석 확정과 좋아요 집계를 다르게 제공합니다. 기능별 성공·보류·잠정 결과를 SLO에 어떻게 반영하나요?

## 구두 답변

좌석 확정은 불확실한 최신 상태에서 성공을 반환하지 않고 보류·거절할 수 있습니다. 좋아요는 잠정 값을 허용하고 수렴·정정 지연을 별도 품질 지표로 둡니다. 두 기능에 같은 성공 정의를 적용하지 않습니다.

분할 중의 정상 정책상 거절과 사용자가 유효한 요청을 완료하지 못한 가용성 영향을 모두 기록합니다. CP 선택이라는 이름으로 사용자 실패를 지표에서 모두 빼지 않습니다. 복구 후 잠정 결과가 어떻게 확정되는지와 이미 준 성공의 불변식도 대조합니다.
