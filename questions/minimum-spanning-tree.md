# 여러 지점을 최소 비용으로 모두 연결하려 합니다. 최소 신장 트리는 최단 경로와 무엇이 다른가요?

## 구두 답변

최소 신장 트리는 연결된 무방향 가중 그래프에서 모든 정점을 연결하면서 간선 비용의 합이 최소인 트리입니다. 한 출발점에서 각 지점까지 가장 싸게 가는 최단 경로 트리와는 목적이 다릅니다. 전체 설치 비용과 개별 이동 비용을 구분해야 합니다.

통신선을 설치한다면 같은 지점을 연결하는 중복 고리를 없애도 연결성을 유지할 수 있어 트리가 후보가 됩니다. 그러나 총 길이가 짧은 트리라고 두 지점 사이의 이동 거리도 원래 그래프에서 최단인 것은 아닙니다. 그래프가 연결되지 않았다면 모든 정점을 잇는 하나의 신장 트리는 없고 각 연결 성분의 숲을 만들 수 있습니다.

저는 회선 설치처럼 전체 합을 줄이는 요구인지, 배송처럼 특정 출발점의 거리를 줄이는 요구인지 먼저 정하겠습니다. MST는 장애 우회 경로가 없는 트리이므로 실제 네트워크의 중복 경로 요구도 별도로 고려해야 합니다. 테스트에서는 연결성, 간선 수, 사이클 부재와 총비용을 확인하겠습니다. 비용만 작다고 연결되지 않은 결과를 정답으로 처리해서는 안 됩니다.

## 득점 포인트

- 전체 연결 비용과 경로 비용을 구분한다.
- 무방향·연결성 전제를 명시한다.
- 트리의 연결·간선·사이클 조건을 확인한다.

## 감점 포인트

- MST 경로가 모든 두 지점의 최단 경로라고 말한다.
- 연결되지 않은 그래프에도 하나의 신장 트리가 있다고 말한다.
- 장애 우회 요구를 최소 비용만으로 해결한다.

## 더 파고들 거리

- 간선 비용이 같으면 MST는 유일할까요?
- 최소 비용 연결에 이중 경로가 필요하면 문제가 어떻게 바뀔까요?
- 음수 간선이 MST 계산에도 항상 문제를 일으킬까요?
