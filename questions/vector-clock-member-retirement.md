# 벡터 시계의 옛 참여자 항목을 삭제하려 합니다. 지연 메시지와 ID 재사용에서 어떤 인과 정보가 사라지나요?

## 구두 답변

벡터의 옛 성분은 지연 이벤트의 인과를 구분하는 정보일 수 있어 항목을 지우면 동시·선후를 오판할 수 있습니다. 안정적인 참여자 퇴역 조건·epoch·축약 방법을 명시해야 합니다.

ID를 재사용할 때 옛 counter와 새 사건을 섞지 않습니다. 모든 참여자가 과거를 관찰했는지 모르는 상태에서 무조건 삭제하지 않습니다. metadata 비용과 보존·재동기화 정책을 장애·복귀 시험으로 검증합니다.
