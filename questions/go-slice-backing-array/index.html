01

구두 답변

정의를 외우기보다, 원리와 조건을 연결해 설명해 보세요.

여기서 ‘복사’가 슬라이스 변수의 대입인지, 원소를 새 배열에 복사한 것인지 구분해야 합니다. 다음 코드에서는 변수는 두 개지만 실제 원소를 담은 배열은 하나입니다.

a := []int{10, 20, 30}
b := a
b[0] = 99

fmt.Println(a) // [99 20 30]
fmt.Println(b) // [99 20 30]

슬라이스는 원소를 직접 담는 배열 자체가 아닙니다. 기반 배열을 가리키는 정보, 길이인 len, 사용할 수 있는 용량인 cap을 가진 값으로 이해하면 됩니다. b := a는 이 정보를 복사하므로 두 슬라이스가 같은 배열을 가리킵니다. b[0]을 바꾸면 a[0]으로 보는 원소도 바뀌는 이유입니다.

원소를 독립적으로 바꾸려면 새 공간을 만들고 복사해야 합니다.

a := []int{10, 20, 30}
b := make([]int, len(a))
copy(b, a)
b[0] = 99

fmt.Println(a) // [10 20 30]
fmt.Println(b) // [99 20 30]

이 예제의 원소는 정수라서 이렇게 하면 독립됩니다. 다만 원소가 포인터나 다른 슬라이스라면 그 안의 참조 대상까지 재귀적으로 복제하는 것은 아닙니다. 새 바깥 배열을 만든 것과 깊은 복사는 구분해야 합니다.

append에서도 같은 공유 문제가 나타날 수 있습니다. 아래처럼 일부만 잘라 만든 슬라이스는 길이 뒤에 사용할 용량이 남아 있습니다.

a := []int{10, 20, 30}
b := a[:1]          // len(b) == 1, cap(b) == 3
b = append(b, 99)    // 기존 배열의 두 번째 칸을 사용

fmt.Println(a) // [10 99 30]
fmt.Println(b) // [10 99]

append가 항상 새 배열을 만드는 것은 아닙니다. 기존 용량이 충분하면 재사용하고, 부족하면 새 기반 배열을 할당합니다. 위에서는 재사용했으므로 원본의 두 번째 값이 바뀝니다. 그렇다고 a의 길이까지 2로 바뀌지는 않습니다. 원소 배열은 공유하지만 각 슬라이스의 길이 정보는 별개이기 때문입니다.

실무에서는 수신 버퍼의 일부를 슬라이스로 잘라 비동기 작업에 넘기는 경우를 조심하겠습니다. 작업이 읽기도 전에 수신 버퍼를 재사용하면 내용이 바뀔 수 있습니다. 함수 실행 중에만 빌리는 데이터라면 공유할 수 있지만, 나중에 사용할 데이터라면 필요한 부분을 복사하거나 완료까지 버퍼의 소유권을 넘기는 계약을 두겠습니다. 값으로 전달했다는 이유만으로 데이터도 독립됐다고 판단하지 않는 것이 핵심입니다.

02

득점 포인트

이해가 드러나는 지점을 확인해 보세요.

  • 변수 대입과 원소 복사를 구분한다. b := a 이후 배열은 공유하지만 길이·용량을 담는 슬라이스 값은 각각 존재한다고 설명한다.
  • append의 결과를 용량으로 설명한다. 위 예제에서 기존 배열의 어느 칸이 바뀌고, 각 슬라이스의 길이는 왜 다른지 설명한다.
  • 복사의 깊이와 수명을 구분한다. 정수 원소 복사와 참조 원소의 얕은 복사, 비동기 보관 시 버퍼 재사용을 각각 다룬다.
03

감점 포인트

놓치기 쉬운 조건과 오해를 짚어 보세요.

  • “Go는 값 전달이므로 슬라이스 원소도 독립적이다”라고 말한다. 복사된 슬라이스 값이 같은 배열을 가리킬 수 있다.
  • “append는 항상 새 배열을 만든다”고 말한다. 용량이 남으면 기존 배열을 재사용해 다른 슬라이스에도 변경이 보일 수 있다.
  • “copy를 호출하면 내부 객체까지 모두 독립된다”고 말한다. 원소가 참조를 포함한다면 그 참조 대상은 여전히 공유될 수 있다.
04

더 파고들 거리

하나 더 질문하며 이해의 범위를 넓혀 보세요.

  • b := a[:1:1]처럼 용량을 제한하면 위 append 예제의 결과는 어떻게 바뀔까요? 그 뒤 b[0]을 직접 수정하는 것도 독립될까요?
  • 큰 버퍼에서 작은 부분만 잘라 오래 보관하면 왜 큰 배열 전체가 메모리에 남을 수 있을까요?
  • 버퍼를 여러 비동기 작업에 공유한다면, 풀에 반환해도 되는 시점을 누가 어떻게 결정해야 할까요?
