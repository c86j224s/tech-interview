# 서버 시계가 갑자기 움직였습니다. lease 경과 계산과 감사 로그 시각을 어떻게 따로 처리하나요?

## 구두 답변

로컬 timeout은 같은 단조 시계로 경과를 재고 감사 표시는 벽시각·시간대·동기화 상태와 논리 ID를 함께 남깁니다. 두 서버의 단조 시각 숫자를 비교해 전역 순서를 만들 수는 없습니다.

벽시각 역행·앞으로 점프·프로세스 재시작에서 lease를 임의 연장하지 않습니다. 실제 권위는 저장 지점의 token·version으로 확인합니다. 감사 로그의 순서를 시각 하나로 확정하지 않고 요청·커밋·인과 링크를 대조합니다.
