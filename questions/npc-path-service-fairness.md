# 여러 NPC가 하나의 경로 서비스에 요청합니다. 행동별 취소와 전체 공정한 탐색 예산을 어떻게 조합하나요?

## 구두 답변

NPC별 최신 목표만 남기고 행동 세대로 늦은 결과를 거절하면서 서비스 전체의 실행·대기 예산을 제한합니다. 취소된 요청이 worker를 즉시 반환하는지 실제 계산 종료와 분리해야 합니다.

같은 문 변경으로 수천 NPC가 재탐색하면 변경·지역별 병합과 round-robin 예산을 둘 수 있습니다. 낮은 우선순위도 최소 진행 기회를 주되 이미 만료된 목표는 실행하지 않습니다. 도달률뿐 아니라 최대 대기·폐기 결과·틱 비용과 맵 snapshot 수명을 측정합니다.

## 득점 포인트

- NPC별 최신 목표만 남기고 행동 세대로 늦은 결과를 거절하면서 서비스 전체의 실행·대기 예산을 제한합니다. 취소된 요청이 worker를 즉시 반환하는지 실제 계산 종료와 분리해야 합니다.
