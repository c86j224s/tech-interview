# 합의 로그를 각 노드가 적용할 때 메일·결제를 직접 호출하면 왜 중복되며 실행 의도는 어디에 저장하나요?

## 구두 답변

모든 복제 노드가 같은 명령을 apply하면서 직접 메일을 보내면 복제 수만큼 외부 효과가 생길 수 있습니다. apply는 결정적인 상태 변경과 내구 실행 의도를 기록하고 외부 호출은 별도 owner·멱등 키 경로에서 수행합니다.

리더만 실행해도 전환과 응답 유실 때문에 중복이 남으므로 역할 검사 하나로 충분하지 않습니다. outbox 상태·요청 ID를 snapshot에 포함하고 재시작 시 이미 완료한 효과를 조회합니다. 합의된 실행 의도와 외부 API의 성공은 다른 확정 지점입니다.
