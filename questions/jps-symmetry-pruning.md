# 균일 비용의 격자에서 A*가 비슷한 경로를 많이 탐색합니다. JPS는 어떤 중간 탐색을 줄이며 어디에서 멈춰야 하나요?

## 구두 답변

JPS는 일정한 격자 이동 비용과 규칙에서 대칭적인 경로를 반복 탐색하지 않도록 중간 노드를 건너뛰는 최적화입니다. 장애물 때문에 선택이 달라지는 점이나 목적지처럼 의미 있는 지점까지 점프합니다. 모든 그래프에서 A*를 더 빠르게 만드는 일반적인 대체재는 아닙니다.

JPS에서 점프한다는 것은 캐릭터가 순간이동한다는 뜻이 아니라, 탐색 후보로 모든 중간 셀을 하나씩 확장하지 않는다는 뜻입니다. 부모가 있는 방향에서 불필요한 대칭 경로를 줄이고, 장애물 때문에 반드시 검토해야 하는 이웃이 생기는 지점에서 선택지를 남깁니다. 이를 강제 이웃이라고 하며 단순히 벽까지 직진하는 규칙과는 다릅니다.

넓고 빈 공간에서 오른쪽으로 갔다 위로 가는 여러 순서가 같은 비용이라면 이를 모두 확장할 필요가 없습니다. JPS는 부모에서 들어온 방향과 주변 장애물을 보고 자연 이웃과 강제 이웃을 구분합니다. 강제 이웃을 무시하면 장애물 옆의 필요한 우회 경로를 놓칠 수 있어 이동 규칙에 맞는 가지치기 증명이 중요합니다.

저는 균일 격자와 정해진 대각 비용 조건을 먼저 확인하겠습니다. 지형별 가중치가 들어가면 기존 가지치기의 전제가 깨질 수 있습니다. 테스트는 빈 맵뿐 아니라 복잡한 모서리와 좁은 통로에서 기본 A*와 비용·도달성을 비교하겠습니다. 탐색 노드가 줄어도 점프 스캔 비용이 커질 수 있으므로 실제 시간과 메모리까지 측정해야 합니다.

## 득점 포인트

- 대칭 제거와 점프의 목적을 설명한다.
- 강제 이웃의 역할을 짚는다.
- 격자·비용·대각 규칙의 적용 조건을 확인한다.

## 감점 포인트

- JPS가 모든 가중 그래프에 그대로 최적이라고 말한다.
- 장애물을 만날 때까지 직선으로만 가면 된다고 말한다.
- 확장 노드 수만으로 속도를 확정한다.

## 더 파고들 거리

- 강제 이웃은 모서리 통과 규칙에 따라 어떻게 달라지나요?
- 대각 점프에서 직교 방향 탐색이 필요한 이유는 무엇인가요?
- 점프 스캔의 반복 비용을 줄이려면 무엇을 전처리할 수 있나요?
