# 중간 장치가 닫은 유휴 연결을 재사용하다 변경 요청이 실패했습니다. 재시도 전에 무엇을 확인하나요?

## 구두 답변

유휴 연결이 끊겼다는 오류라도 요청 바이트 일부가 원본에 도착했는지 불확실할 수 있습니다. API·라이브러리의 전송 상태와 논리 멱등성을 확인한 뒤 재시도합니다.

GET 이름만 보고 안전하다고 가정하지 않고 실제 부수 효과를 봅니다. 변경은 같은 요청 키로 결과를 조회하고 연결 재생성·retry budget을 제한합니다. idle timeout·NAT·서버 drain을 바꿔 재현합니다.
