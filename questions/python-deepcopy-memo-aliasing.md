# deepcopy는 순환과 같은 객체를 가리키는 여러 참조를 어떻게 처리하나요? memo가 없다면 어떤 문제가 생기나요?

memo는 이미 복사한 원본 객체와 새 객체의 대응을 저장해 순환 재귀를 끝내고 같은 원본을 가리키던 별칭을 복사본에서도 유지하는 데 사용됩니다.
