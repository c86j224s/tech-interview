# 객체 크기와 이동률이 다른 월드에서 uniform grid와 동적 AABB 트리를 어떤 부하로 비교하나요?

## 구두 답변

격자는 셀 계산과 국소 갱신이 단순하지만 크기 차이·밀집 지역에서 다중 등록과 후보 폭증이 생길 수 있습니다. 동적 AABB 트리는 다양한 경계를 다루기 좋을 수 있으나 트리 갱신·회전·포인터 접근 비용을 가집니다.

동일 장면에서 이동률·크기 분포·핫스팟·긴 sweep을 바꿔 후보 수와 정밀 검사·갱신 p99를 비교합니다. 기준 전수 충돌 결과의 실제 쌍이 후보에 모두 포함되는지 먼저 검사합니다. 평균 후보 감소를 충돌 누락과 교환하지 않습니다.
