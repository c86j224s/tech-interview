# 기기 로그인 승인 뒤 토큰 교환 응답을 잃었습니다. 승인 상태와 자격 발급·재전달을 어떻게 구분하나요?

## 구두 답변

사용자 승인이 완료된 상태와 기기용 토큰이 발급·소비된 상태를 분리합니다. 토큰 응답을 잃었다고 user code를 다시 승인하거나 새 자격을 무조건 발급하면 중복·혼동이 생길 수 있습니다.

발급 transaction·기기 요청 ID·짧은 재전달 정책을 사용하되 raw token 저장은 암호화·수명·접근을 제한합니다. 해시만으로 원문 토큰을 재전달할 수는 없습니다. 기기와 브라우저의 권한·코드 수명·취소를 함께 검사합니다.
