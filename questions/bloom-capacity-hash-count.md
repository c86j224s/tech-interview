# 예상 원소 수와 거짓 양성률 목표가 있습니다. 블룸 필터의 비트 수와 해시 수를 어떻게 계산하고 검증하나요?

## 구두 답변

독립 균등 해시를 가정하면 거짓 양성률은 대략 (1-exp(-kn/m))^k로 모델링할 수 있습니다. 원하는 n·p에서 m≈-n ln p/(ln2)^2, k≈(m/n)ln2를 출발점으로 삼되 정수 반올림과 실제 hash 비용을 확인합니다.

예상보다 많은 원소가 들어오면 비트가 포화돼 오류율이 커집니다. 실제 부재 키의 통과 비율로 검증하고 존재 비율에 좌우되는 양성 중 오답 비율과 구분합니다. 필터가 신규 키를 놓치거나 잘못 삭제하면 이 계산의 거짓 음성 없음 전제도 깨집니다.
