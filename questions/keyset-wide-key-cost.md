# 페이지 커서의 보조 키를 길게 만들었습니다. 결정적 정렬의 이점과 인덱스·전송 비용을 어떻게 비교하나요?

## 구두 답변

유일한 보조 키는 동률 페이지 경계를 결정하지만 넓은 키는 인덱스 fan-out·cache·비교·커서 전송량을 늘립니다. 클러스터링 키가 보조 인덱스에 포함되는 엔진이면 여러 인덱스에 비용이 반복될 수 있습니다.

짧고 안정적인 ID를 보조 키로 쓸지, 원래 복합 업무 키가 꼭 필요한지 비교합니다. 키를 줄이려고 유일성·정렬 의미를 잃으면 안 됩니다. 대표 페이지 크기·동점 분포·쓰기 부하에서 읽기량·cursor 크기·인덱스 유지비를 측정합니다.
