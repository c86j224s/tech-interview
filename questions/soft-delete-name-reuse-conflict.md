# 탈퇴 계정의 이름을 재사용한 뒤 원래 계정을 복구합니다. 활성 행 고유 제약과 복구 충돌은 어떻게 다루나요?

## 구두 답변

활성 행만 유일한 이름을 점유한다면 탈퇴 후 재사용과 원래 계정 복구는 충돌할 수 있습니다. 복구 시 새 이름 요구·기존 활성 사용자 보호·수동 확인 중 정책을 명시합니다.

현재 활성 행의 UNIQUE·부분 인덱스 조건을 최종 권위로 사용합니다. 복구 전에 조회만 하고 나중 활성화하면 동시 가입과 경쟁합니다. 이름과 내부 불변 계정 ID를 분리하고 구매·제재·로그인 연결을 임의로 다른 계정에 옮기지 않습니다.
