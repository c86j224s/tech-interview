# 서버 이벤트 순서는 일부만 정해져 있습니다. 통합 테스트에서 유효한 비결정적 순서를 어떻게 표현하나요?

## 구두 답변

전체 이벤트 목록을 한 순서로 고정하지 않고 반드시 앞서야 하는 관계와 독립 사건을 분리합니다. 로그인 성공 뒤 행동 허용 같은 인과는 검증하고 서로 독립적인 알림의 순서는 허용할 수 있습니다.

집합만 비교하면 중복·누락 횟수를 놓치므로 다중집합·이벤트 ID·키별 순번을 사용합니다. 최종 상태도 검사해 잘못된 중간 효과가 숨지 않게 합니다. 기다림은 고정 sleep보다 상태 조건과 기한을 쓰고 실제로 금지된 순서를 주입해 테스트가 실패하는지 확인합니다.
