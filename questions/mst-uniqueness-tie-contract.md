# 동점 간선이 있으면 항상 MST가 여러 개인가요? 유일성과 올바른 결과 검증은 어떤 조건으로 판단하나요?

## 구두 답변

모든 간선 가중치가 서로 다르면 MST 유일성이 보장되지만 동점이 있다고 반드시 여러 MST가 생기는 것은 아닙니다. 대체 간선으로 같은 비용의 다른 트리를 만들 수 있는 구조인지 봅니다.

동점에서 deterministic 간선 ID를 쓰면 결과 재현을 돕지만 최적성 증명은 별도입니다. 연결·cycle 부재·V-1 간선·최소 총비용을 검증하고 간선 목록 하나만 정답으로 고정하지 않습니다.
