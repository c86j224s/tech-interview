# 간선 비용이 0 또는 1인 그래프에서 최단 거리를 구합니다. 0-1 BFS는 deque의 앞과 뒤를 어떻게 쓰나요?

## 구두 답변

현재 노드에서 비용 0 간선으로 개선한 후보는 deque 앞, 비용 1 간선은 뒤에 넣어 가까운 거리 후보를 먼저 처리합니다. 일반 BFS의 첫 방문 고정 대신 거리 완화가 필요한 구현 규칙을 따릅니다.

0 비용 우회가 나중에 더 짧은 경로를 만들 수 있어 이미 발견됐다는 이유만으로 개선을 무시하지 않습니다. 오래된 후보와 중복을 처리하고 비음수 0·1 범위를 벗어나면 다른 알고리즘을 씁니다. 작은 그래프의 Dijkstra와 거리·도달성을 비교합니다.
