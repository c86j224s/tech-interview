# 일부 시간 조회가 vDSO로 처리됩니다. 커널 진입을 줄이면서 시간 정보를 어떻게 안전하게 읽나요?

vDSO는 커널이 제공한 코드·데이터를 사용자 공간에서 활용해 일부 시간 조회의 syscall 진입을 줄일 수 있습니다. 모든 시계·플랫폼·조건에서 항상 같은 빠른 경로를 쓰는 것은 아닙니다.
