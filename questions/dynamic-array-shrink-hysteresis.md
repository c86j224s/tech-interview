# 배열 사용량이 경계 근처에서 오르내려 확장·축소가 반복됩니다. 서로 다른 임계값은 왜 필요한가요?

## 구두 답변

확장 직후의 사용률 근처에서 축소하면 추가·삭제를 번갈아 할 때 매번 배열을 복사할 수 있습니다. 예를 들어 절반 사용 시 축소 대신 1/4 이하에서 절반으로 줄이면 두 경계 사이 여유가 생깁니다.

정책은 구현·메모리 요구에 맞춰 정하고 최소 용량·최대 크기·reserve를 고려합니다. 반복 경계 입력에서 재할당 수·최대 지연·메모리 피크를 측정합니다. 공간을 즉시 줄이는 것과 전체 연산의 상환 비용을 동시에 최적화하기 어렵다는 대가를 명시합니다.

## 득점 포인트
