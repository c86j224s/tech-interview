# 같은 보조 인덱스 조회를 힙과 클러스터드 테이블에서 실행합니다. 행 locator와 추가 읽기 비용은 어떻게 다른가요?

## 구두 답변

보조 인덱스의 locator가 힙의 행 위치인지 클러스터링 키인지 엔진별로 확인합니다. 키를 찾은 뒤 원본 행과 MVCC 가시성을 읽는 비용이 추가될 수 있어 인덱스 조회 성공만으로 전체 비용을 판단하지 않습니다.

적은 결과와 큰 결과에서 lookup 횟수·랜덤 페이지 읽기·covering 여부를 비교합니다. 클러스터링 키가 넓으면 보조 인덱스 공간에도 영향을 줄 수 있습니다. 테이블 재구성 비용과 쓰기 분할·잠금도 함께 측정합니다.
