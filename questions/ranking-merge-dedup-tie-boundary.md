# 샤드 후보에 같은 사용자가 중복되고 K위 동점자가 많습니다. 병합의 중복·동점 범위를 어떻게 정하나요?

## 구두 답변

사용자의 원본 소유 샤드와 점수 집계 의미를 먼저 확인합니다. 같은 사용자의 복제 후보를 단순 합산하면 중복이고 실제 분할 점수라면 누락 없이 합쳐야 합니다.

동점자를 정확히 K명인지 모두 반환할지 결정하고 같은 comparator·version을 씁니다. dedup으로 후보 수가 줄면 다음 후보가 더 필요한지 확인합니다. 부분 샤드 결과를 전역 확정으로 표시하지 않습니다.

## 득점 포인트

- 사용자의 원본 소유 샤드와 점수 집계 의미를 먼저 확인합니다. 같은 사용자의 복제 후보를 단순 합산하면 중복이고 실제 분할 점수라면 누락 없이 합쳐야 합니다.
- 부분 샤드 결과를 전역 확정으로 표시하지 않습니다.
