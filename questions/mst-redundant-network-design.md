# 최소 비용으로 연결한 트리에 단일 회선 장애 대응도 필요합니다. MST만으로 부족한 이유와 추가 조건은 무엇인가요?

## 구두 답변

MST는 간선 하나가 끊기면 트리가 분리될 수 있어 이중 경로·용량·지연 요구를 만족하지 못합니다. 최소 비용의 목표에 장애 허용 제약을 추가한 다른 최적화 문제입니다.

중요 연결의 bridge·대체 경로·장애 영역을 분석하고 필요한 여분 간선을 선택합니다. 단순히 MST를 두 번 구해 독립성이 생긴다고 가정하지 않습니다. 실제 회선 비용·최대 지연·단일 실패를 검증합니다.
