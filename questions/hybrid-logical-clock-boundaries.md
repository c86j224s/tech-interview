# 물리 시각에 가까운 값과 논리 증가를 함께 쓰는 HLC는 어떤 순서를 표현하며 동시성·최신성을 어디까지 보장하나요?

## 구두 답변

HLC는 물리 시간에 가까운 성분과 논리 카운터를 결합해 로컬·수신 이벤트의 인과 순서를 거스르지 않도록 증가시킵니다. 시계가 뒤로 가도 논리 증가로 순서를 유지할 수 있지만 실제 벽시각 정확성을 보장하지는 않습니다.

HLC 대소만으로 두 사건이 인과 관계인지 동시인지 완전히 구분할 수 없습니다. 미래 시각 입력·overflow·재시작 상태를 관리하고 병합 규칙은 별도로 둡니다. 로그 정렬·버전 선택에 쓰는 범위와 선형화 보장을 혼동하지 않습니다.
