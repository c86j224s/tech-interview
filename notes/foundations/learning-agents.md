# 머신러닝·AI 에이전트 기초

메일의 특정 단어를 발견하면 스팸으로 분류하는 규칙을 직접 작성할 수 있습니다. 하지만 표현이 계속 바뀌고 여러 단서가 함께 작용하면 규칙을 관리하기 어려워집니다. 머신러닝은 데이터를 이용해 예측에 필요한 매개변수를 정하는 접근입니다. AI 에이전트는 그 모델의 판단을 도구 실행과 관찰에 연결하는 시스템이며, 학습 자체와는 다른 층입니다.

## 입력·모델·예측

메일에서 얻은 입력을 x, 정답을 y라고 하고 모델의 예측을 f(x;θ)로 나타낼 수 있습니다. θ는 학습으로 바꿀 매개변수입니다. 간단한 선형 모형은 입력 특징에 가중치를 곱해 합산합니다. 더 복잡한 모델도 입력과 매개변수로 출력을 계산한다는 관점은 유지됩니다.

스팸 점수가 0.8이라고 나왔다고 곧바로 보정된 실제 확률 80%라고 볼 수는 없습니다. 모델의 학습 목적과 보정 상태를 확인해야 합니다. 실제 차단은 점수와 임계값을 비교하는 별도 결정입니다.

## 손실과 학습

예측이 정답에서 얼마나 벗어났는지를 손실 함수로 계산합니다. 학습은 훈련 데이터의 손실 등을 줄이도록 θ를 갱신하는 과정입니다. 경사하강법은 현재 매개변수에서 손실이 증가하는 방향을 계산하고 반대 방향으로 작은 보폭만큼 이동합니다.

보폭이 너무 크면 좋은 값을 지나치거나 발산할 수 있고, 너무 작으면 진행이 느립니다. 손실이 줄어도 사용자가 원하는 결과가 항상 좋아지는 것은 아닙니다. 정상 메일 차단의 비용과 스팸 누락의 비용이 다르면 실제 평가 지표와 운영 임계값을 따로 정해야 합니다.

## 훈련·검증·테스트

시험 문제를 미리 외운 학생의 점수로 새로운 문제 해결 능력을 판단하기 어렵듯, 모델을 조정한 데이터에서만 좋은 결과가 나오는지 확인해서는 부족합니다. 훈련 데이터는 매개변수 학습, 검증 데이터는 설정과 후보 선택, 테스트 데이터는 최종 평가에 사용합니다.

같은 사용자의 비슷한 메일이 양쪽에 섞이거나 미래 정보를 특징으로 넣으면 결과가 과하게 좋아질 수 있습니다. 전처리의 평균이나 어휘 목록도 훈련 범위에서 얻어야 합니다. 분할은 파일을 세 개 만드는 행위보다 어떤 정보를 어떤 단계까지 볼 수 있는지 정하는 규칙입니다.

## 분류 결과와 운영 결정

| 실제 상태·판정 | 의미 |
| --- | --- |
| 스팸을 스팸으로 판정 | 참 양성 |
| 정상 메일을 스팸으로 판정 | 거짓 양성 |
| 스팸을 정상으로 판정 | 거짓 음성 |
| 정상 메일을 정상으로 판정 | 참 음성 |

스팸이 드물면 모든 메일을 정상으로 분류해도 정확도가 높게 나올 수 있습니다. 스팸으로 고른 것 중 실제 스팸 비율인 정밀도와, 실제 스팸 중 찾아낸 비율인 재현율을 함께 보는 이유입니다. 검토 인력이 하루 100건만 처리할 수 있다면 검토로 보내는 양도 정책의 일부입니다.

## 모델 출력과 에이전트 실행

모델이 ‘메일을 보관하라’는 출력을 만들었다고 메일 서버의 상태가 바뀌지는 않습니다. 실행기가 허용된 도구와 인자를 검사하고 실제 API를 호출해야 합니다. 도구가 작업 ID만 반환했다면 접수일 수 있어 최종 완료를 별도로 확인합니다.
