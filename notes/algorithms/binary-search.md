# 이진 탐색과 경계 불변식

## 찾으려는 것은 값인가, 첫 참 위치인가

정렬 배열에서 target을 찾는 문제는 **target 이상인 첫 위치**를 찾고 그 값이 target인지 확인하는 문제로 표현할 수 있습니다. 이 경계가 lower_bound입니다. 값이 없으면 삽입 위치를 반환하고, 모든 값이 작으면 배열 길이 n을 반환합니다.

더 일반적으로는 `false, false, …, true, true`처럼 한 번만 바뀌는 단조 조건의 첫 참 위치를 찾습니다. 조건이 중간에 다시 거짓이 되면 이 알고리즘을 적용할 수 없습니다.

## 구현과 불변식

```python
def lower_bound(a, target):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

반복마다 `[0, lo)`의 값은 모두 target보다 작고 `[hi, n)`의 값은 모두 target 이상입니다. 원소를 읽는 미확정 구간은 `[lo, hi)`입니다. 답으로 반환할 경계는 n을 포함할 수 있으므로 **배열 접근 가능한 인덱스와 경계 후보**를 혼동하면 안 됩니다.

- `a[mid] < target`이면 mid까지 답이 아니므로 `lo = mid + 1`입니다.
- 아니면 mid가 답일 수 있으므로 `hi = mid`입니다.
- 매번 구간이 줄어들고 `lo == hi`이면 그 위치가 첫 참 경계입니다.

## 예제로 비교하기

배열 `[1, 2, 2, 4]`에서 다음과 같습니다.

| target | lower_bound | upper_bound | 동등 구간 |
| --- | ---: | ---: | --- |
| 2 | 1 | 3 | `[1,3)` |
| 3 | 3 | 3 | 빈 구간 |
| 5 | 4 | 4 | 빈 구간, 끝 삽입 위치 |

upper_bound는 **target보다 큰 첫 위치**입니다. 위 코드의 `<`를 `<=`로 바꾸면 같은 구간 불변식 아래 구현할 수 있습니다. 두 경계의 차이로 동등 원소 수를 구합니다.

### target 2를 찾는 세 번의 판단

같은 배열에서 `lower_bound(a, 2)`를 실행해 보겠습니다. 시작 범위는 `[0, 4)`이고, 여기서 4는 마지막 원소의 인덱스가 아니라 배열 끝 경계입니다.

| 반복 전 lo·hi | mid와 값 | 판단 | 다음 lo·hi |
| --- | --- | --- | --- |
| 0·4 | mid=2, 값=2 | 2 이상이므로 mid가 첫 위치일 수도 있음 | 0·2 |
| 0·2 | mid=1, 값=2 | 아직 왼쪽에 같은 값이 있을 수도 있음 | 0·1 |
| 0·1 | mid=0, 값=1 | 1은 target보다 작으므로 0은 제외 | 1·1 |

마지막에는 읽을 미확정 원소가 남지 않고 `lo=hi=1`이 됩니다. 첫 반복에서 값 2를 찾았다고 즉시 반환했다면 인덱스 2를 돌려주어 **첫 번째 2**라는 요구를 놓쳤을 것입니다. 같은 값이 있는지 찾는 문제와 그 값의 첫 위치를 찾는 문제가 다른 지점입니다.

## 종료와 숫자 범위

시간은 O(log n), 보조 공간은 반복 구현에서 O(1)입니다. `lo + (hi-lo)//2`는 `lo+hi`의 overflow를 피하지만 `hi-lo`가 표현 가능하다는 전제가 필요합니다. Python 정수는 자동 확장되지만 고정 폭 정수 언어는 전체 탐색 범위와 signed·unsigned 혼합을 확인해야 합니다.

실수 탐색에서는 중간값이 반올림으로 끝점과 같아질 수 있습니다. 허용 오차·반복 상한·정체 감지를 정하고, 숫자 오차를 무시한 `lo != hi` 종료에 의존하지 않습니다.

## 다른 문제에 적용할 때

- 정렬 문자열: 저장과 탐색에서 같은 정규화·대소문자·collation을 사용합니다.
- 복합 키: 첫 값이 같을 때 보조 키까지 같은 비교 순서를 적용합니다.
- 누적 가중치: 가중치가 비음수여야 누적값이 단조라는 전제가 유지됩니다.
- 시간·용량의 정답 탐색: 판정 함수가 실제로 단조인지 증명해야 합니다. 비싼 판정 함수의 비용도 전체 시간에 곱해집니다.

## 흔한 실패

반환값 n을 바로 `a[n]`으로 읽거나, `hi=mid-1` 규칙을 반열린 코드에 섞거나, `lo=mid`로 바꾸어 길이 1 구간에서 정체하는 오류가 흔합니다. 한 가지 구간 표현을 정해 끝까지 유지하는 것이 중요합니다.

## 연습

1. 빈 배열과 target이 양끝 밖인 경우를 손으로 실행합니다.
2. 선형 스캔과 무작위 배열의 결과를 비교합니다.
3. 매 반복에 불변식을 assertion으로 확인합니다.
4. 정렬 기준을 바꾸었을 때 탐색 비교도 함께 바꾸지 않으면 실패하는 사례를 만듭니다.
